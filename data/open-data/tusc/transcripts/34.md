# ข้อบังคับมหาวิทยาลัยธรรมศาสตร์
# ว่าด้วยการจัดตั้งและบริหารกองทุนเพื่อสนับสนุนการประกันอุบัติเหตุของนักศึกษาและบุคลากรมหาวิทยาลัยธรรมศาสตร์ พ.ศ. ๒๕๖๔

โดยที่เป็นการสมควรให้มีข้อบังคับมหาวิทยาลัยธรรมศาสตร์ว่าด้วยการจัดตั้งและบริหารเพื่อสนับสนุนการประกันอุบัติเหตุของนักศึกษาและบุคลากรมหาวิทยาลัยธรรมศาสตร์ ซึ่งคณะกรรมการการเงิน ได้พิจารณาโดยอาศัยอำนาจตามข้อ ๕๒ ของข้อบังคับมหาวิทยาลัยธรรมศาสตร์ว่าด้วยการบริหารการเงิน งบประมาณ และการบัญชี พ.ศ. ๒๕๖๔ และให้ความเห็นชอบแล้ว ในคราวประชุมครั้งที่ ๓/๒๕๖๔ เมื่อวันที่ ๒๐ สิงหาคม ๒๕๖๔

อาศัยอำนาจตามความในมาตรา ๒๓ (๒) และ (๔) แห่งพระราชบัญญัติมหาวิทยาลัยธรรมศาสตร์ พ.ศ. ๒๕๕๘ สภามหาวิทยาลัยในการประชุมครั้งที่ ๙/๒๕๖๔ เมื่อวันที่ ๓๐ สิงหาคม ๒๕๖๔ จึงเห็นชอบให้ออกข้อบังคับไว้ ดังนี้

<a id="clause-1"></a>**ข้อ ๑** ข้อบังคับนี้เรียกว่า "ข้อบังคับมหาวิทยาลัยธรรมศาสตร์ว่าด้วยการจัดตั้งและบริหารกองทุนเพื่อสนับสนุนการประกันอุบัติเหตุของนักศึกษาและบุคลากรมหาวิทยาลัยธรรมศาสตร์ พ.ศ. ๒๕๖๔"

<a id="clause-2"></a>**ข้อ ๒** ข้อบังคับนี้ให้ใช้บังคับตั้งแต่วันถัดจากวันประกาศเป็นต้นไป

<a id="clause-3"></a>**ข้อ ๓** ในข้อบังคับนี้

"กองทุน" หมายความว่า กองทุนเพื่อสนับสนุนการประกันอุบัติเหตุของนักศึกษาและบุคลากร มหาวิทยาลัยธรรมศาสตร์

<a id="clause-4"></a>**ข้อ ๔** ให้จัดตั้งกองทุนเพื่อสนับสนุนการประกันอุบัติเหตุของนักศึกษาและบุคลากร มหาวิทยาลัยธรรมศาสตร์ขึ้นโดยมีวัตถุประสงค์ ดังต่อไปนี้

1. (๑) เพื่อให้ความช่วยเหลือในการเบิกเงินทดรองจ่ายให้แก่นักศึกษาและบุคลากรของมหาวิทยาลัยธรรมศาสตร์ทุกคนที่เอาประกันภัย โดยดำเนินการผ่านมหาวิทยาลัยในระหว่างที่ยังไม่ได้รับค่าสินไหมทดแทนจากบริษัทประกันภัย
2. (๒) เพื่อช่วยเหลือจ่ายสมทบเป็นค่ารักษาพยาบาลให้แก่นักศึกษาและบุคลากรของมหาวิทยาลัยธรรมศาสตร์ที่ประสบอุบัติเหตุเกินวงเงินที่ได้รับจากบริษัทประกันภัย และไม่สามารถเบิกจากที่อื่นได้ ทั้งนี้ให้อยู่ในดุลพินิจของคณะกรรมการกองทุน
3. (๓) เพื่อช่วยเหลือตามประเพณีนิยมแก่ผู้เอาประกันภัยที่ประสบอุบัติเหตุ
4. (๔) เพื่อส่งเสริมและสนับสนุนให้นักศึกษาและบุคลากรของมหาวิทยาลัยธรรมศาสตร์เอาประกันอุบัติเหตุ และได้รับความคุ้มครองจากการเอาประกันภัยดังกล่าว

<a id="clause-5"></a>**ข้อ ๕** รายรับซึ่งเป็นรายได้ของกองทุน มีดังต่อไปนี้

1. (๑) เงินที่มหาวิทยาลัยธรรมศาสตร์จัดสรรให้
2. (๒) เงินที่มีผู้มอบให้เพื่อสมทบกองทุน
3. (๓) ดอกผลของกองทุน
4. (๔) เงินหรือผลประโยชน์อื่นใดที่ได้จากการบริหารกองทุน

<!-- page 2 -->

<a id="clause-6"></a>**ข้อ ๖** รายจ่ายกองทุน มีดังต่อไปนี้

1. (๑) รายจ่ายตามวัตถุประสงค์ของกองทุน
2. (๒) รายจ่ายเกี่ยวกับการบริหารและจัดการกองทุน

<a id="clause-7"></a>**ข้อ ๗** ให้มีคณะกรรมการกองทุน ประกอบด้วย รองอธิการบดีฝ่ายการนักศึกษาเป็นประธาน ผู้อำนวยการกองกิจการนักศึกษา ประธานสภาอาจารย์หรือผู้แทน ประธานสภาข้าราชการหรือผู้แทน ผู้อำนวยการกองคลังหรือผู้แทน นายกองค์การนักศึกษาหรือผู้แทน ประธานสภานักศึกษาหรือผู้แทน เป็นกรรมการ หัวหน้างานอนามัยเป็นกรรมการและเลขานุการ และเจ้าหน้าที่งานอนามัยที่หัวหน้างานอนามัยมอบหมายหนึ่งคนเป็นกรรมการและผู้ช่วยเลขานุการ

<a id="clause-8"></a>**ข้อ ๘** ให้คณะกรรมการกองทุนมีอำนาจหน้าที่ดำเนินการให้เป็นไปตามวัตถุประสงค์ของกองทุนและให้หมายความรวมถึง

1. (๑) พิจารณาการใช้จ่ายเงินกองทุน
2. (๒) พิจารณาแผนงานหรือโครงการประจำปี
3. (๓) ดำเนินการอื่นใดตามที่อธิการบดีมอบหมาย

<a id="clause-9"></a>**ข้อ ๙** ให้กองคลังมีหน้าที่ในการเก็บรักษาเงิน ตลอดจนการปฏิบัติทางบัญชีให้ถูกต้อง

<a id="clause-10"></a>**ข้อ ๑๐** ให้กองทุนเพื่อสนับสนุนการประกันอุบัติเหตุของนักศึกษาและบุคลากร มหาวิทยาลัยธรรมศาสตร์ ตามระเบียบมหาวิทยาลัยธรรมศาสตร์ว่าด้วยกองทุนเพื่อสนับสนุนการประกันอุบัติเหตุของนักศึกษาและบุคลากรมหาวิทยาลัยธรรมศาสตร์ พ.ศ. ๒๕๔๘ เป็นกองทุนตามข้อบังคับนี้

<a id="clause-11"></a>**ข้อ ๑๑** ให้คณะกรรมการซึ่งดำรงอยู่ก่อนวันที่ข้อบังคับนี้มีผลใช้บังคับปฏิบัติหน้าที่คณะกรรมการตามข้อบังคับนี้ต่อไปจนกว่าจะได้มีการแต่งตั้งคณะกรรมการตามข้อบังคับนี้

<a id="clause-12"></a>**ข้อ ๑๒** ให้การดำเนินการตามระเบียบมหาวิทยาลัยธรรมศาสตร์ว่าด้วยกองทุนเพื่อสนับสนุนการประกันอุบัติเหตุของนักศึกษาและบุคลากรมหาวิทยาลัยธรรมศาสตร์ พ.ศ. ๒๕๔๘ อยู่ก่อนวันที่ข้อบังคับนี้มีผลใช้บังคับให้ดำเนินการตามระเบียบเดิมต่อไปจนกว่าจะแล้วเสร็จ

<a id="clause-13"></a>**ข้อ ๑๓** ให้อธิการบดีรักษาการตามข้อบังคับนี้ และให้มีอำนาจออกประกาศมหาวิทยาลัย กำหนดหลักเกณฑ์และอัตราการใช้จ่ายเงินกองทุนให้เป็นไปตามข้อบังคับนี้ได้

ประกาศ ณ วันที่ ๓๐ เดือน สิงหาคม พ.ศ. ๒๕๖๔

# ข้อบังคับมหาวิทยาลัยธรรมศาสตร์
# ว่าด้วยกองทุนเพื่อเสริมสร้างความเป็นนานาชาติ (ฉบับที่ ๒) พ.ศ. ๒๕๖๖

โดยที่เป็นการสมควรปรับปรุงหลักเกณฑ์การบริหารกองทุนเพื่อการแลกเปลี่ยนนักศึกษาให้ครอบคลุมการดำเนินงานด้านการส่งเสริมความเป็นนานาชาติของมหาวิทยาลัยธรรมศาสตร์

อาศัยอำนาจตามความในมาตรา ๒๓ (๔) แห่งพระราชบัญญัติมหาวิทยาลัยธรรมศาสตร์ พ.ศ. ๒๕๕๘ สภามหาวิทยาลัย ในการประชุมครั้งที่ ๔/๒๕๖๖ เมื่อวันที่ ๒๘ มีนาคม พ.ศ. ๒๕๖๖ ออกข้อบังคับไว้ ดังนี้

<a id="amend-clause-1"></a>**ข้อ ๑** ข้อบังคับนี้เรียกว่า "ข้อบังคับมหาวิทยาลัยธรรมศาสตร์ ว่าด้วยกองทุนเพื่อเสริมสร้างความเป็นนานาชาติ (ฉบับที่ ๒) พ.ศ. ๒๕๖๖"

<a id="amend-clause-2"></a>**ข้อ ๒** ข้อบังคับนี้ให้ใช้บังคับตั้งแต่วันถัดจากวันประกาศเป็นต้นไป

<a id="amend-clause-3"></a>**ข้อ ๓** ให้ยกเลิกความในข้อ ๑๒ (๒) ของข้อบังคับมหาวิทยาลัยธรรมศาสตร์ ว่าด้วยกองทุนเพื่อเสริมสร้างความเป็นนานาชาติ พ.ศ. ๒๕๖๕ และให้ใช้ความต่อไปนี้แทน

# ข้อบังคับมหาวิทยาลัยธรรมศาสตร์
# ว่าด้วยกองทุนเพื่อเสริมสร้างความเป็นนานาชาติ พ.ศ. ๒๕๖๕

โดยที่เป็นการสมควรปรับปรุงหลักเกณฑ์การบริหารกองทุนบริหารกองทุนเพื่อการแลกเปลี่ยนนักศึกษา ให้ครอบคลุมการดำเนินงานด้านการส่งเสริมความเป็นนานาชาติของมหาวิทยาลัยธรรมศาสตร์

อาศัยอำนาจตามความในมาตรา ๒๓ (๔) แห่งพระราชบัญญัติมหาวิทยาลัยธรรมศาสตร์ พ.ศ. ๒๕๕๘ สภามหาวิทยาลัยในการประชุมครั้งที่ ๙/๒๕๖๕ เมื่อวันที่ ๑๙ กันยายน ๒๕๖๕ ออกข้อบังคับไว้ ดังนี้

<a id="clause-1"></a>**ข้อ ๑** ข้อบังคับนี้เรียกว่า "ข้อบังคับมหาวิทยาลัยธรรมศาสตร์ว่าด้วยกองทุนเพื่อเสริมสร้างความเป็นนานาชาติ พ.ศ. ๒๕๖๕"

<a id="clause-2"></a>**ข้อ ๒** ข้อบังคับนี้ให้ใช้บังคับตั้งแต่วันถัดจากวันประกาศเป็นต้นไป

<a id="clause-3"></a>**ข้อ ๓** ให้ยกเลิกข้อบังคับมหาวิทยาลัยธรรมศาสตร์ว่าด้วยการจัดตั้งและบริหารกองทุนเพื่อการแลกเปลี่ยนนักศึกษา พ.ศ. ๒๕๖๔

<a id="clause-4"></a>**ข้อ ๔** ในข้อบังคับนี้

"มหาวิทยาลัย" หมายความว่า มหาวิทยาลัยธรรมศาสตร์

"อธิการบดี" หมายความว่า อธิการบดีมหาวิทยาลัยธรรมศาสตร์

"กองทุน" หมายความว่า กองทุนเพื่อเสริมสร้างความเป็นนานาชาติ

"กองทุน (ชื่อคณะ)" หมายความว่า กองทุนเพื่อเสริมสร้างความเป็นนานาชาติ (ชื่อคณะ)

"คณะกรรมการ" หมายความว่า คณะกรรมการกองทุนเพื่อเสริมสร้างความเป็นนานาชาติ

"คณะ" ให้หมายความรวมถึงวิทยาลัย สถาบัน หรือส่วนงานที่เรียกชื่ออย่างอื่นที่มีฐานะเทียบเท่าคณะ วิทยาลัย หรือสถาบันที่มีหน้าที่จัดการศึกษา

"คณบดี" ให้หมายความรวมถึงผู้อำนวยการสถาบัน หรือหัวหน้าส่วนงานที่เรียกอย่างอื่นที่มีหน้าที่จัดการศึกษา

"เสริมสร้างความเป็นนานาชาติ" หมายความว่า การแลกเปลี่ยน การพัฒนาศักยภาพของนักศึกษาและบุคลากร ระบบบริหารจัดการ ทรัพยากรและสิ่งแวดล้อมทางกายภาพที่เกี่ยวข้องกับความเป็นนานาชาติ

"นักศึกษาแลกเปลี่ยน" หมายความว่า นักศึกษาในโครงการแลกเปลี่ยนนักศึกษา และให้หมายความรวมถึงนักศึกษาในโครงการรับเข้าศึกษาในระยะสั้นหรือโครงการอื่นเพื่อเสริมสร้างความเป็นนานาชาติตามมติคณะกรรมการ

<!-- page 3 -->

<a id="clause-5"></a>**ข้อ ๕** ให้กองทุนเพื่อการแลกเปลี่ยนนักศึกษาตามข้อบังคับมหาวิทยาลัยธรรมศาสตร์ว่าด้วยการจัดตั้งและบริหารกองทุนเพื่อการแลกเปลี่ยนนักศึกษา พ.ศ. ๒๕๖๔ เป็นกองทุนเพื่อเสริมสร้างความเป็นนานาชาติตามข้อบังคับนี้

ให้กองทุนเพื่อการแลกเปลี่ยนนักศึกษาระดับคณะตามตามข้อบังคับมหาวิทยาลัยธรรมศาสตร์ว่าด้วยการจัดตั้งและบริหารกองทุนเพื่อการแลกเปลี่ยนนักศึกษา พ.ศ. ๒๕๖๔ เป็นกองทุนเพื่อเสริมสร้างความเป็นนานาชาติ (ชื่อคณะ) ตามข้อบังคับนี้

<a id="clause-6"></a>**ข้อ ๖** หลักเกณฑ์และวิธีการเกี่ยวกับการบริหารกองทุนนอกเหนือจากที่กำหนดไว้ตามข้อบังคับนี้ ให้ปฏิบัติตามข้อบังคับมหาวิทยาลัยธรรมศาสตร์ว่าด้วยการบริหารการเงิน งบประมาณ และการบัญชี

<a id="clause-7"></a>**ข้อ ๗** ให้อธิการบดีรักษาการให้เป็นไปตามข้อบังคับนี้

## หมวด ๑ การจัดตั้งกองทุน

<a id="clause-8"></a>**ข้อ ๘** ให้จัดตั้งกองทุนเรียกว่า "กองทุนเพื่อเสริมสร้างความเป็นนานาชาติ" มีวัตถุประสงค์เพื่อส่งเสริมและสนับสนุนการดำเนินงานของมหาวิทยาลัยเพื่อความเป็นนานาชาติ และการแลกเปลี่ยนนักศึกษาระหว่างมหาวิทยาลัยกับสถาบันการศึกษาหรือหน่วยงานของในประเทศและต่างประเทศ

<a id="clause-9"></a>**ข้อ ๙** รายได้และทรัพย์สินของกองทุน มีดังต่อไปนี้

1. (๑) เงินอุดหนุนจากมหาวิทยาลัย
2. (๒) ค่าธรรมเนียม ค่าบำรุง ค่าบริการ หรือค่าใช้จ่ายอื่น ที่เรียกเก็บจากนักศึกษาในโครงการแลกเปลี่ยนนักศึกษาของมหาวิทยาลัย
3. (๓) เงินหรือทรัพย์สินที่มีผู้อุทิศให้
4. (๔) เงินหรือผลประโยชน์อื่นที่ได้จากการดำเนินงาน
5. (๕) เงินหรือผลประโยชน์อื่นที่ได้จากการลงทุน

<a id="clause-10"></a>**ข้อ ๑๐** รายได้ของกองทุนให้จ่ายได้เฉพาะเพื่อการดำเนินงานตามวัตถุประสงค์ของกองทุนและตามรายการ ดังต่อไปนี้

1. (๑) จัดสรรเป็นค่าธรรมเนียม ค่าบำรุง ค่าบริการ และค่าใช้จ่ายอื่นของนักศึกษาแลกเปลี่ยน
2. (๒) จัดสรรเป็นทุนการศึกษาและทุนเพื่อช่วยเหลือค่าใช้จ่ายเกี่ยวกับการศึกษาของนักศึกษาแลกเปลี่ยน
3. (๓) จัดสรรเป็นค่าใช้จ่ายการจัดโครงการรับเข้าศึกษาในระยะสั้น เช่น Short Program, Summer Program เป็นต้น
4. (๔) จัดสรรเป็นค่าใช้จ่ายการจัดกิจกรรมเสริมสร้างศักยภาพความเป็นนานาชาติของบุคลากร
5. (๕) จัดสรรเป็นค่าใช้จ่ายในการพัฒนาระบบเทคโนโลยี (IT) และทรัพยากรทางกายภาพเพื่อรองรับความเป็นนานาชาติ
6. (๖) ค่าใช้จ่ายอื่นเพื่อการเสริมสร้างความเป็นนานาชาติตามที่คณะกรรมการกำหนด

## หมวด ๒ การบริหารกองทุน

<a id="clause-11"></a>**ข้อ ๑๑** ให้มีคณะกรรมการประกอบด้วย

1. (๑) รองอธิการบดีที่กำกับดูแลด้านวิเทศสัมพันธ์ เป็นประธานกรรมการ
2. (๒) ผู้ช่วยอธิการบดีซึ่งอธิการบดีมอบหมาย เป็นรองประธานกรรมการ
3. (๓) ผู้อำนวยการกองคลังและผู้อำนวยการกองกิจการนักศึกษา เป็นกรรมการ
4. (๔) กรรมการซึ่งดำรงตำแหน่งคณบดีจำนวนสี่คน เป็นกรรมการ
5. (๕) ผู้อำนวยการกองวิเทศสัมพันธ์ เป็นกรรมการและเลขานุการ

ให้ผู้อำนวยการกองวิเทศสัมพันธ์มอบหมายเจ้าหน้าที่กองวิเทศสัมพันธ์เป็นผู้ช่วยเลขานุการได้ไม่เกินจำนวนสองคน

<a id="clause-12"></a>**ข้อ ๑๒** คณะกรรมการมีหน้าที่และอำนาจ ดังต่อไปนี้

1. (๑) พิจารณาแผนงานโครงการแลกเปลี่ยนนักศึกษา โครงการรับเข้าศึกษาในระยะสั้น และโครงการอื่นเพื่อเสริมสร้างความเป็นนานาชาติตามมติคณะกรรมการและรายงานอธิการบดีเพื่อพิจารณาให้ความเห็นชอบ
2. (๒) พิจารณางบประมาณประจำปีของกองทุน เสนอต่ออธิการบดีเพื่อพิจารณาให้ความเห็นชอบและเสนอสภามหาวิทยาลัยเพื่อพิจารณาอนุมัติ
3. (๓) พิจารณาหลักเกณฑ์และอัตราการจ่ายเงินของกองทุนเพื่อใช้ตามวัตถุประสงค์ของกองทุนและเสนอต่ออธิการบดีออกเป็นประกาศมหาวิทยาลัย
4. (๔) พิจารณาจัดสรรทุนการศึกษาและทุนช่วยเหลือค่าใช้จ่ายเพื่อการศึกษาให้แก่นักศึกษาแลกเปลี่ยน
5. (๕) กำหนดหลักเกณฑ์ในการดำเนินการต่าง ๆ ตามวัตถุประสงค์ของกองทุน
6. (๖) ดำเนินการเพื่อนำเงินรายได้ของกองทุนไปหารายได้หรือลงทุน
7. (๗) พิจารณาจัดทำผลการดำเนินงานและฐานะทางการเงินประจำปีของกองทุนเสนอต่อสภามหาวิทยาลัยเพื่อทราบทุกสิ้นปีงบประมาณ

## หมวด ๓ กองทุนเพื่อเสริมสร้างความเป็นนานาชาติ (ชื่อคณะ)

<a id="clause-13"></a>**ข้อ ๑๓** ในคณะที่มีโครงการแลกเปลี่ยนนักศึกษาอาจจัดให้มีกองทุน เรียกว่า "กองทุนเพื่อเสริมสร้างความเป็นนานาชาติ (ชื่อคณะ)" มีวัตถุประสงค์เพื่อส่งเสริมและสนับสนุนการดำเนินงานของคณะเพื่อความเป็นนานาชาติ และการแลกเปลี่ยนนักศึกษาระหว่างคณะกับสถาบันการศึกษาหรือหน่วยงานของในประเทศและต่างประเทศ

<a id="clause-14"></a>**ข้อ ๑๔** รายได้และทรัพย์สินของกองทุน (ชื่อคณะ) มีดังต่อไปนี้

1. (๑) เงินอุดหนุนจากเงินรายได้ของส่วนงาน

<!-- page 5 -->

2. (๒) ค่าธรรมเนียม ค่าบำรุง ค่าบริการ หรือค่าใช้จ่ายอื่น ที่เรียกเก็บจากนักศึกษาในโครงการแลกเปลี่ยนนักศึกษาของคณะ
3. (๓) เงินหรือทรัพย์สินที่มีผู้อุทิศให้
4. (๔) เงินหรือผลประโยชน์อื่นที่ได้จากการดำเนินงาน
5. (๕) เงินหรือผลประโยชน์อื่นที่ได้จากการลงทุน

<a id="clause-15"></a>**ข้อ ๑๕** รายได้ของกองทุน (ชื่อคณะ) ให้จ่ายได้เฉพาะเพื่อการดำเนินงานตามวัตถุประสงค์ของกองทุน (ชื่อคณะ) และตามรายการ ดังต่อไปนี้

1. (๑) จัดสรรเป็นค่าธรรมเนียม ค่าบำรุง ค่าบริการ และค่าใช้จ่ายอื่นของนักศึกษาแลกเปลี่ยนของคณะ
2. (๒) จัดสรรเป็นทุนการศึกษาและทุนเพื่อช่วยเหลือค่าใช้จ่ายเกี่ยวกับการศึกษาของนักศึกษาแลกเปลี่ยนของคณะ
3. (๓) จัดสรรเป็นค่าใช้จ่ายการจัดโครงการรับเข้าศึกษาในระยะสั้น เช่น Short Program หรือ Summer Program
4. (๔) จัดสรรเป็นค่าใช้จ่ายการจัดกิจกรรมเสริมสร้างศักยภาพความเป็นนานาชาติของบุคลากรของคณะ
5. (๕) ค่าใช้จ่ายอื่นที่เกี่ยวกับการเสริมสร้างความเป็นนานาชาติตามที่คณะกรรมการกองทุน (ชื่อคณะ) กำหนด

<a id="clause-16"></a>**ข้อ ๑๖** ให้มีคณะกรรมการกองทุน (ชื่อคณะ) ประกอบด้วยคณบดี เป็นประธานกรรมการและกรรมการซึ่งคณบดีแต่งตั้งจำนวนไม่น้อยกว่าห้าคนแต่ไม่เกินเจ็ดคน

ให้เลขานุการคณะเป็นกรรมการและเลขานุการ และอาจให้มีผู้ช่วยเลขานุการจากผู้ปฏิบัติงานภายในคณะได้ไม่เกินจำนวนสองคน

<a id="clause-17"></a>**ข้อ ๑๗** คณะกรรมการกองทุน (ชื่อคณะ) มีหน้าที่และอำนาจ ดังต่อไปนี้

1. (๑) พิจารณาแผนงานโครงการแลกเปลี่ยนนักศึกษาของคณะเสนอต่อคณบดีเพื่อพิจารณาให้ความเห็นชอบ
2. (๒) พิจารณางบประมาณประจำปีของกองทุน (ชื่อคณะ) เสนอต่อคณบดีเพื่อพิจารณาให้ความเห็นชอบ
3. (๓) พิจารณาหลักเกณฑ์และอัตราการจ่ายเงินของกองทุน (ชื่อคณะ) เพื่อใช้ตามวัตถุประสงค์ของกองทุนและเสนอคณบดีเพื่อออกเป็นประกาศส่วนงาน
4. (๔) พิจารณาจัดสรรทุนการศึกษาและทุนช่วยเหลือค่าใช้จ่ายเพื่อการศึกษาให้แก่นักศึกษาแลกเปลี่ยนของคณะ
5. (๕) กำหนดหลักเกณฑ์ในการดำเนินการต่าง ๆ ตามวัตถุประสงค์ของกองทุน (ชื่อคณะ)
6. (๖) ดำเนินการเพื่อนำเงินรายได้ของกองทุน (ชื่อคณะ) ไปหารายได้หรือลงทุน
7. (๗) พิจารณาจัดทำผลการดำเนินงานและฐานะทางการเงินประจำปีของกองทุน (ชื่อคณะ) เสนอต่ออธิการบดีเพื่อเสนอสภามหาวิทยาลัยเพื่อทราบทุกสิ้นปีงบประมาณ

<a id="clause-19"></a>**ข้อ ๑๙** การดำเนินการตามกองทุนเพื่อการแลกเปลี่ยนนักศึกษา (วิเทศสัมพันธ์) ที่มีอยู่ก่อนวันที่ข้อบังคับนี้มีผลใช้บังคับ ให้ดำเนินการตามหลักเกณฑ์และวิธีการที่กำหนดไว้ในข้อบังคับมหาวิทยาลัยว่าด้วยการจัดตั้งและการบริหารกองทุนเพื่อการแลกเปลี่ยนนักศึกษาต่อไปจนกว่าการดำเนินการจะแล้วเสร็จหรือสิ้นสุดลง

# ระเบียบกิจกรรมนักศึกษามหาวิทยาลัยธรรมศาสตร์ ว่าด้วยกลุ่มอิสระกิจกรรมนักศึกษามหาวิทยาลัยธรรมศาสตร์ สังกัดองค์การนักศึกษามหาวิทยาลัยธรรมศาสตร์ พ.ศ. 2566

โดยที่เป็นการสมควรให้มีระเบียบว่าด้วยกลุ่มอิสระกิจกรรมนักศึกษามหาวิทยาลัยธรรมศาสตร์ สังกัดองค์การนักศึกษามหาวิทยาลัยธรรมศาสตร์ เพื่อให้มีการกำกับดูแลโดยองค์การนักศึกษามหาวิทยาลัยธรรมศาสตร์ และกำหนดแนวทางในการจัดสรรงบประมาณกิจกรรมนักศึกษาอย่างชัดเจน

อาศัยอำนาจตามความในข้อ 10 (3) แห่งข้อบังคับมหาวิทยาลัยธรรมศาสตร์ว่าด้วยกิจกรรมนักศึกษามหาวิทยาลัยธรรมศาสตร์ พ.ศ. 2563 สภานักศึกษามหาวิทยาลัยธรรมศาสตร์เห็นชอบให้ออกระเบียบไว้ ดังนี้

<a id="clause-1"></a>**ข้อ 1** ระเบียบนี้เรียกว่า "ระเบียบกิจกรรมนักศึกษามหาวิทยาลัยธรรมศาสตร์ว่าด้วยกลุ่มอิสระกิจกรรมนักศึกษามหาวิทยาลัยธรรมศาสตร์ สังกัดองค์การนักศึกษามหาวิทยาลัยธรรมศาสตร์ พ.ศ. 2566"

<a id="clause-2"></a>**ข้อ 2** ระเบียบนี้ให้ใช้บังคับตั้งแต่วันถัดจากวันประกาศเป็นต้นไป

<a id="clause-3"></a>**ข้อ 3** ในระเบียบนี้

"กลุ่มอิสระ" หมายถึง กลุ่มอิสระกิจกรรมนักศึกษามหาวิทยาลัยธรรมศาสตร์

"กลุ่มอิสระสังกัดองค์การนักศึกษา" หมายถึง กลุ่มอิสระกิจกรรมนักศึกษามหาวิทยาลัยธรรมศาสตร์ สังกัดองค์การนักศึกษามหาวิทยาลัยธรรมศาสตร์

<a id="clause-4"></a>**ข้อ 4** ให้นายกองค์การนักศึกษาเป็นผู้รักษาการตามระเบียบนี้

## หมวด 1 บททั่วไป

<a id="clause-5"></a>**ข้อ 5** กลุ่มอิสระเป็นการรวมตัวกันของนักศึกษาระดับปริญญาตรีเพื่อทำกิจกรรมนักศึกษาอย่างใดอย่างหนึ่งภายในมหาวิทยาลัยธรรมศาสตร์ซึ่งมิได้เป็นกิจกรรมนักศึกษาภายในคณะ และมิได้มีการจัดตั้งเป็นชุมนุม

<!-- page 2 -->

<a id="clause-6"></a>**ข้อ 6** ให้กลุ่มอิสระซึ่งได้จดทะเบียนตามระเบียบนี้เป็นกลุ่มอิสระสังกัดองค์การนักศึกษา

ให้กลุ่มอิสระสังกัดองค์การนักศึกษาอยู่ภายใต้กำกับดูแลของคณะกรรมการบริหารองค์การนักศึกษา

<a id="clause-7"></a>**ข้อ 7** การใดซึ่งระเบียบนี้มิได้กำหนดไว้โดยเฉพาะ ให้นำข้อบังคับ ระเบียบ หรือประกาศว่าด้วยชุมนุม และข้อบังคับ ระเบียบ หรือประกาศอื่นที่เกี่ยวข้องมาใช้บังคับเท่าที่พอจะใช้บังคับได้

## หมวด 2 การจดทะเบียนและการเพิกถอนการจดทะเบียนกลุ่มอิสระสังกัดองค์การนักศึกษา

<a id="clause-8"></a>**ข้อ 8** กลุ่มอิสระซึ่งจะจดทะเบียนเป็นกลุ่มอิสระสังกัดองค์การนักศึกษา ต้องมีนักศึกษาปริญญาตรีของมหาวิทยาลัยธรรมศาสตร์จำนวนไม่น้อยกว่าสิบคนที่มาจากคณะต่าง ๆ ยื่นคำร้องขอจดทะเบียน พร้อมแจ้งวัตถุประสงค์ของกลุ่มอิสระต่อคณะกรรมการบริหารองค์การนักศึกษา

ในกรณีที่กลุ่มอิสระใดมีคุณสมบัติไม่ครบถ้วนตามที่กำหนดไว้ในวรรคหนึ่ง ให้กลุ่มอิสระดังกล่าวยื่นคำชี้แจงถึงเหตุผลและความจำเป็นต่อคณะกรรมการบริหารองค์การนักศึกษาเพื่อให้พิจารณาจดทะเบียนเป็นกรณีพิเศษ

ให้คณะกรรมการบริหารองค์การนักศึกษาขอเอกสาร หรือเรียกประธานกลุ่มอิสระหรือผู้ที่เกี่ยวข้องเข้าชี้แจงเพื่อประกอบการพิจารณาตามวรรคหนึ่งและวรรคสองได้

<a id="clause-9"></a>**ข้อ 9** เมื่อคณะกรรมการบริหารองค์การนักศึกษาได้รับคำร้องขอจดทะเบียนกลุ่มอิสระสังกัดองค์การนักศึกษา ให้คณะกรรมการบริหารองค์การนักศึกษาพิจารณาคำร้องดังกล่าวให้แล้วเสร็จภายในสามสิบวันนับแต่วันที่ได้รับคำร้อง หากคณะกรรมการบริหารองค์การนักศึกษาพิจารณาเห็นชอบ ให้รับจดทะเบียนไว้ แต่หากคณะกรรมการบริหารองค์การนักศึกษาพิจารณาไม่เห็นชอบ ให้แสดงเหตุผลไว้ในหนังสือแจ้งผลการพิจารณาด้วย

ให้คณะกรรมการบริหารองค์การนักศึกษามีหนังสือแจ้งผลการพิจารณาภายในเจ็ดวันนับแต่วันที่พิจารณาแล้วเสร็จ ทั้งในกรณีที่พิจารณาเห็นชอบและพิจารณาไม่เห็นชอบ

<a id="clause-10"></a>**ข้อ 10** การจดทะเบียนกลุ่มอิสระสังกัดองค์การนักศึกษาให้มีอายุนับแต่วันจดทะเบียนจนถึงวันสิ้นปีการศึกษา

ให้กลุ่มอิสระสังกัดองค์การนักศึกษาที่ใกล้สิ้นอายุการจดทะเบียนสามารถจดทะเบียนใหม่ได้ตั้งแต่หกสิบวันก่อนวันสิ้นปีการศึกษา

<a id="clause-11"></a>**ข้อ 11** หลักเกณฑ์และวิธีการดำเนินการขอจดทะเบียนกลุ่มอิสระสังกัดองค์การนักศึกษาให้เป็นไปตามที่ประกาศองค์การนักศึกษากำหนด

<!-- page 3 -->

<a id="clause-12"></a>**ข้อ 12** คณะกรรมการบริหารองค์การนักศึกษาอาจพิจารณาเพิกถอนการจดทะเบียนกลุ่มอิสระสังกัดองค์การนักศึกษาได้ด้วยเหตุอย่างใดอย่างหนึ่ง ดังนี้

1. (1) มีคุณสมบัติไม่ครบถ้วนตามที่กำหนดไว้ในข้อ 8 วรรคหนึ่ง เว้นแต่ได้มีการยื่นคำชี้แจงถึงเหตุผลและความจำเป็นต่อคณะกรรมการบริหารองค์การนักศึกษา และคณะกรรมการบริหารองค์การนักศึกษาพิจารณายกเว้นเป็นกรณีพิเศษ
2. (2) มีการดำเนินงานขัดต่อวัตถุประสงค์ตามที่ได้แจ้งไว้ต่อคณะกรรมการบริหารองค์การนักศึกษา
3. (3) มีการจัดกิจกรรมหรือการดำเนินงานใด ๆ อันเป็นการละเมิดต่อสิทธิและเสรีภาพ หรือมีการบังคับ ขู่เข็ญให้กระทำการหรืองดเว้นกระทำการอย่างหนึ่งอย่างใด หรือมีเหตุอื่นในทำนองเดียวกัน ทั้งต่อสมาชิกหรือบุคคลอื่น

คณะกรรมการบริหารองค์การนักศึกษาต้องให้กลุ่มอิสระสังกัดองค์การนักศึกษามีโอกาสทราบข้อเท็จจริงที่เกี่ยวข้องกับการพิจารณาตามวรรคหนึ่งอย่างเพียงพอ และมีโอกาสได้โต้แย้งและแสดงพยานหลักฐานของตน

ให้คณะกรรมการบริหารองค์การนักศึกษาขอเอกสาร หรือเรียกผู้ที่เกี่ยวข้องเข้าชี้แจงเพื่อประกอบการพิจารณาตามวรรคหนึ่งได้

ในกรณีที่คณะกรรมการบริหารองค์การนักศึกษาพิจารณาให้มีการเพิกถอนการจดทะเบียนกลุ่มอิสระสังกัดองค์การนักศึกษา ให้คณะกรรมการบริหารองค์การนักศึกษามีหนังสือแจ้งผลการพิจารณาเพิกถอนภายในเจ็ดวันนับแต่วันที่พิจารณาแล้วเสร็จ

## หมวด 3 คณะกรรมการบริหารกลุ่มอิสระสังกัดองค์การนักศึกษา

<a id="clause-13"></a>**ข้อ 13** ให้คณะกรรมการบริหารกลุ่มอิสระสังกัดองค์การนักศึกษา ประกอบไปด้วย

1. (1) ประธานกลุ่มอิสระสังกัดองค์การนักศึกษา
2. (2) รองประธานกลุ่มอิสระสังกัดองค์การนักศึกษา
3. (3) เลขานุการกลุ่มอิสระสังกัดองค์การนักศึกษา
4. (4) กรรมการกลุ่มอิสระสังกัดองค์การนักศึกษาฝ่ายการเงิน

ให้คณะกรรมการบริหารกลุ่มอิสระสังกัดองค์การนักศึกษามีกรรมการอื่นนอกเหนือจากที่กำหนดไว้ในวรรคหนึ่งได้อีกไม่เกินสามคน

<!-- page 4 -->

<a id="clause-14"></a>**ข้อ 14** ให้คณะกรรมการบริหารกลุ่มอิสระสังกัดองค์การนักศึกษามีหน้าที่ ดังต่อไปนี้

1. (1) แจ้งรายชื่อประธานกลุ่มอิสระสังกัดองค์การนักศึกษาและคณะกรรมการบริหารกลุ่มอิสระสังกัดองค์การนักศึกษาต่อคณะกรรมการบริหารองค์การนักศึกษา
2. (2) แจ้งรายชื่อและจำนวนสมาชิกต่อคณะกรรมการบริหารองค์การนักศึกษา
3. (3) จัดทำและรายงานผลการดำเนินโครงการ การดำเนินงาน บัญชีรายรับ ร่ายจ่าย [sic] ตลอดจนทรัพย์สิน ต่อคณะกรรมการบริหารองค์การนักศึกษา ทั้งนี้ เป็นไปตามที่ประกาศองค์การนักศึกษากำหนด

## หมวด 4 การดำเนินงานของกลุ่มอิสระสังกัดองค์การนักศึกษา

<a id="clause-15"></a>**ข้อ 15** การดำเนินงานทั้งปวงของกลุ่มอิสระสังกัดองค์การนักศึกษา ต้องไม่ขัดต่อกฎหมาย ข้อบังคับ ระเบียบ หรือคำสั่งของมหาวิทยาลัย และต้องอยู่ภายในขอบแห่งวัตถุประสงค์ตามที่ได้แจ้งไว้ต่อคณะกรรมการบริหารองค์การนักศึกษา

## หมวด 5 งบประมาณของกลุ่มอิสระสังกัดองค์การนักศึกษา

<a id="clause-16"></a>**ข้อ 16** ให้กลุ่มอิสระซึ่งได้จดทะเบียนเป็นกลุ่มอิสระสังกัดองค์การนักศึกษาสามารถเสนอแผนงานโครงการ และงบประมาณกิจกรรมนักศึกษาประจำปีต่อคณะกรรมการบริหารองค์การนักศึกษา เพื่อเสนอให้สภานักศึกษาพิจารณาอนุมัติได้

<a id="clause-17"></a>**ข้อ 17** ให้กลุ่มอิสระสังกัดองค์การนักศึกษาได้รับการพิจารณาจัดสรรงบประมาณกิจกรรมไม่เกินสามหมื่นบาทต่อปีการศึกษา

ในกรณีที่กลุ่มอิสระสังกัดองค์การนักศึกษาจำเป็นต้องขอบประมาณกิจกรรมเกินกว่าที่กำหนดไว้ในวรรคหนึ่ง ให้กลุ่มอิสระดังกล่าวยื่นคำชี้แจงถึงเหตุผลและความจำเป็นต่อคณะกรรมการบริหารองค์การนักศึกษา เพื่อเสนอให้สภานักศึกษาพิจารณาอนุมัติเป็นกรณีพิเศษ

ให้คณะกรรมการบริหารองค์การนักศึกษาและสภานักศึกษาขอเอกสาร หรือเรียกประธานกลุ่มอิสระสังกัดองค์การนักศึกษาหรือผู้ที่เกี่ยวข้องเข้าชี้แจงหรือให้ความเห็นเพื่อประกอบการพิจารณาตามวรรคหนึ่งและวรรคสองได้

### บทเฉพาะกาล

<a id="clause-18"></a>**ข้อ 18** ให้กลุ่มอิสระซึ่งได้จดทะเบียนต่อคณะกรรมการบริหารองค์การนักศึกษาก่อนวันที่ระเบียบนี้มีผลใช้บังคับเป็นกลุ่มอิสระสังกัดองค์การนักศึกษาตามระเบียบนี้

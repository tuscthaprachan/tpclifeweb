# ข้อบังคับมหาวิทยาลัยธรรมศาสตร์
# ว่าด้วยการจัดตั้งและบริหารกองทุนเงินอุดหนุนกิจกรรมนักศึกษา พ.ศ. ๒๕๖๔

โดยที่เป็นการสมควรให้มีข้อบังคับมหาวิทยาลัยธรรมศาสตร์ว่าด้วยการจัดตั้งและบริหารกองทุนเงินอุดหนุนกิจกรรมนักศึกษาซึ่งคณะกรรมการการเงิน ได้พิจารณาโดยอาศัยอำนาจตามข้อ ๕๒ ของข้อบังคับมหาวิทยาลัยธรรมศาสตร์ว่าด้วยการบริหารการเงิน งบประมาณ และการบัญชี พ.ศ.๒๕๖๔ และให้ความเห็นชอบแล้ว ในคราวประชุมครั้งที่ ๓/๒๕๖๔ เมื่อวันที่ ๒๐ สิงหาคม ๒๕๖๔

อาศัยอำนาจตามความในมาตรา ๒๓ (๒) และ (๔) แห่งพระราชบัญญัติมหาวิทยาลัยธรรมศาสตร์ พ.ศ. ๒๕๕๘ สภามหาวิทยาลัยในการประชุมครั้งที่ ๙/๒๕๖๔ เมื่อวันที่ ๓๐ สิงหาคม ๒๕๖๔ จึงเห็นชอบให้ออกข้อบังคับไว้ ดังนี้

<a id="clause-1"></a>**ข้อ ๑** ข้อบังคับฉบับนี้เรียกว่า "ข้อบังคับมหาวิทยาลัยธรรมศาสตร์ ว่าด้วยการจัดตั้งและบริหารกองทุนเงินอุดหนุนกิจกรรมนักศึกษา พ.ศ.๒๕๖๔"

<a id="clause-2"></a>**ข้อ ๒** ข้อบังคับนี้มีผลบังคับใช้นับถัดจากวันประกาศเป็นต้นไป

<a id="clause-3"></a>**ข้อ ๓** ให้ยกเลิกระเบียบมหาวิทยาลัยธรรมศาสตร์ว่าด้วยการจัดตั้งและบริหารกองทุนเงินอุดหนุนกิจกรรมนักศึกษา พ.ศ.๒๕๕๙

<a id="clause-4"></a>**ข้อ ๔** ในระเบียบนี้

"กองทุน" หมายถึง กองทุนเงินอุดหนุนกิจกรรมนักศึกษา มหาวิทยาลัยธรรมศาสตร์

"คณะกรรมการบริหาร" หมายถึง คณะกรรมการบริหารกองทุนเงินอุดหนุนกิจกรรมนักศึกษา

"องค์การนักศึกษา" หมายถึง องค์การนักศึกษามหาวิทยาลัยธรรมศาสตร์

"สภานักศึกษา" หมายถึง สภานักศึกษามหาวิทยาลัยธรรมศาสตร์

<a id="clause-5"></a>**ข้อ ๕** ให้อธิการบดี รักษาการให้เป็นไปตามระเบียบนี้

## หมวดที่ ๑ การจัดตั้งกองทุนและคณะกรรมการบริหาร

<a id="clause-6"></a>**ข้อ ๖** ให้จัดตั้งกองทุนเงินอุดหนุนกิจกรรมนักศึกษา โดยให้นำเงินเข้าอุดหนุนกิจกรรมนักศึกษาที่จัดเก็บจากนักศึกษามหาวิทยาลัยธรรมศาสตร์ ตามระเบียบ ข้อบังคับที่สภามหาวิทยาลัยธรรมศาสตร์ให้ความเห็นชอบเข้าเป็นรายได้ของกองทุน

<a id="clause-7"></a>**ข้อ ๗** เงินกองทุนและดอกผลให้ใช้ได้เพื่อสนับสนุนการดำเนินกิจกรรมที่ส่งเสริมและพัฒนานักศึกษาให้มีงบประมาณในการทำกิจกรรมมากขึ้น โดยมีหลักเกณฑ์วิธีการในการพิจารณา และเป็นการส่งเสริมกิจกรรมนักศึกษาให้มีประสิทธิภาพมากขึ้น

<!-- page 2 -->

<a id="clause-8"></a>**ข้อ ๘** รายได้และทรัพย์สินของกองทุน มีดังนี้

1. (๑) เงินอุดหนุนกิจกรรมนักศึกษา ที่เรียกเก็บจากนักศึกษา
2. (๒) เงินหรือทรัพย์สินซึ่งมีผู้บริจาคให้
3. (๓) รายได้หรือผลประโยชน์จากการลงทุน
4. (๔) รายได้อื่นๆ

<a id="clause-9"></a>**ข้อ ๙** ให้มีคณะกรรมการบริหารกองทุนเงินอุดหนุนกิจกรรมนักศึกษา ซึ่งประกอบด้วย รองอธิการบดีที่รับผิดชอบด้านกิจกรรมนักศึกษาเป็นประธาน และกรรมการที่อธิการบดีแต่งตั้งอีกไม่เกินหกคนเป็นกรรมการ จากผู้แทนรองคณบดีหรือผู้ช่วยคณบดีที่รับผิดชอบด้านกิจกรรมนักศึกษา จำนวนสามคน ผู้แทนองค์การนักศึกษา จำนวนสองคน และผู้แทนสภานักศึกษา จำนวนหนึ่งคน

ให้อธิการบดีแต่งตั้งเจ้าหน้าที่ กองกิจการนักศึกษา ที่รับผิดชอบด้านกิจกรรมนักศึกษาคนหนึ่งเป็นเลขานุการคณะกรรมการบริหาร

อธิการบดีแต่งตั้งผู้ทรงคุณวุฒิซึ่งเป็นที่ปรึกษาคณะกรรมการบริหารก็ได้

ให้คณะกรรมการบริหารและที่ปรึกษาที่อธิการบดีแต่งตั้ง มีวาระในการดำรงตำแหน่งคราวละสามปี

## หมวดที่ ๒ การบริหารกองทุน

<a id="clause-10"></a>**ข้อ ๑๐** ให้คณะกรรมการบริหาร มีอำนาจหน้าที่บริหารกองทุนอุดหนุนกิจกรรมนักศึกษา ให้เป็นไปตามวัตถุประสงค์ โดยเฉพาะอย่างยิ่งให้มีอำนาจหน้าที่ดังต่อไปนี้

1. (๑) พิจารณาอนุมัติการจัดสรรเงินกองทุนและดอกผลในระเบียบนี้
2. (๒) พิจารณาความเหมาะสมของโครงการที่ขออนุมัติดำเนินการ โดยใช้เงินจากกองทุน
3. (๓) พิจารณาดำเนินการเกี่ยวกับการนำเข้ากองทุนไปลงทุนหาผลประโยชน์ ภายในขอบเขตที่ระบุไว้ในระเบียบมหาวิทยาลัยธรรมศาสตร์ ว่าด้วยการเก็บเงินและทรัพย์สินของมหาวิทยาลัย
4. (๔) พิจารณากำหนดหลักเกณฑ์วิธีปฏิบัติ และศึกษาค่าใช้จ่ายตามความจำเป็นและความเหมาะสม โดยทำเป็นประกาศของอธิการบดี
5. (๕) ดำเนินการอื่นใดตามที่กำหนดไว้ในระเบียบนี้

<a id="clause-11"></a>**ข้อ ๑๑** ให้คณะกรรมการบริหาร พิจารณาเงินกองทุนเพื่อประโยชน์แก่การส่งเสริมกิจกรรมนักศึกษา ทั้งนี้ คณะกรรมการอาจกำหนดวงเงินให้ประธานคณะกรรมการมีอำนาจในการพิจารณาอนุมัติได้

<a id="clause-12"></a>**ข้อ ๑๒** ให้กองคลัง มหาวิทยาลัยธรรมศาสตร์ มีหน้าที่รับจ่ายเงิน และเก็บรักษาเงินกองทุน ตลอดจนการปฏิบัติทางบัญชีให้ถูกต้อง

<!-- page 3 -->

## หมวดที่ ๓ โครงการที่ขอรับการจัดสรรเงินกองทุนต่อคณะกรรมการบริหาร

<a id="clause-13"></a>**ข้อ ๑๓** โครงการที่ขอรับการจัดสรรกองทุนเงินอุดหนุนกิจกรรมนักศึกษาให้องค์การนักศึกษามหาวิทยาลัยธรรมศาสตร์เป็นผู้พิจารณา โดยได้รับความเห็นชอบจากสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ปีละสองครั้ง

<a id="clause-14"></a>**ข้อ ๑๔** เมื่อสภานักศึกษาให้ความเห็นชอบแล้วให้เสนอโครงการดังกล่าวกับ คณะกรรมการบริหารพิจารณาครั้งที่หนึ่งภายในเดือนสิงหาคม และครั้งที่สองภายในเดือนเมษายน เพื่อให้ทันกับการใช้เงินกองทุนในปีการศึกษา นั้น

<a id="clause-15"></a>**ข้อ ๑๕** องค์การนักศึกษามหาวิทยาลัยธรรมศาสตร์อาจเสนอโครงการมาเพื่อขอรับการจัดสรรเงินกองทุนเป็นการเพิ่มเติม หรือขอเปลี่ยนแปลงโครงการที่ได้รับการจัดสรรเงินกองทุนแล้วต่อคณะกรรมการบริหารก็ได้

การเสนอโครงการเพื่อขอรับการจัดสรรเงินกองทุนเป็นการเพิ่มเติม หรือขอเปลี่ยนแปลงโครงการต้องได้รับความเห็นชอบจากสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ก่อน และจะต้องเป็นไปตามขั้นตอนและหลักเกณฑ์ที่กำหนดไว้ในหมวดนี้

## หมวดที่ ๔ การควบคุมการตรวจสอบ

<a id="clause-16"></a>**ข้อ ๑๖** หลักเกณฑ์การจัดทำโครงการเพื่อเสนอขอรับการจัดสรรเงินกองทุน ขั้นตอนวิธีปฏิบัติ และอัตราค่าใช้จ่ายความจำเป็นและความเหมาะสมให้เป็นไปตามที่อธิการบดีกำหนด โดยทำเป็นประกาศของอธิการบดี

<a id="clause-17"></a>**ข้อ ๑๗** ให้อธิการบดีรายงานผลการปฏิบัติงานตามโครงการที่ได้รับจัดสรรและสถานะทางการเงินของกองทุน ตลอดทั้งความคาดหมายเกี่ยวกับการจัดเก็บเงินอุดหนุนกิจกรรมนักศึกษาและแนวทางการจัดสรรเงินกองทุนในปีต่อไปให้สภามหาวิทยาลัยทราบทุกสิ้นปีงบประมาณรายจ่ายจากรายได้ของมหาวิทยาลัย

<a id="clause-18"></a>**ข้อ ๑๘** ให้สำนักงานตรวจสอบภายใน ตรวจสอบการเงินของกองทุน แล้วรายงานต่ออธิการบดี เพื่อเสนอต่อสภามหาวิทยาลัย ภายในกำหนดเวลาที่ระบุไว้ในข้อบังคับมหาวิทยาลัยธรรมศาสตร์ว่าด้วยการบริหารการเงิน งบประมาณ และการบัญชี

<a id="clause-19"></a>**ข้อ ๑๙** ในกรณีที่ข้อบังคับนี้มิได้บัญญัติหลักเกณฑ์ในเรื่องใดไว้โดยเฉพาะให้ปฏิบัติตามข้อบังคับมหาวิทยาลัยธรรมศาสตร์ว่าด้วยการบริหารการเงิน งบประมาณ และการบัญชี โดยอนุโลม

<!-- page 4 -->

## บทเฉพาะกาล

<a id="clause-20"></a>**ข้อ ๒๐** ให้กองทุนอุดหนุนกิจกรรมนักศึกษา ตามระเบียบมหาวิทยาลัยธรรมศาสตร์ว่าด้วยเงินกองทุนอุดหนุนกิจกรรมนักศึกษา พ.ศ.๒๕๕๙ เป็นกองทุนตามข้อบังคับนี้

<a id="clause-21"></a>**ข้อ ๒๑** ให้คณะกรรมการซึ่งดำรงตำแหน่งอยู่ก่อนวันที่ข้อบังคับนี้มีผลใช้บังคับปฏิบัติหน้าที่คณะกรรมการตามข้อบังคับนี้ต่อไปจนกว่าจะได้มีการแต่งตั้งคณะกรรมการตามข้อบังคับนี้

<a id="clause-22"></a>**ข้อ ๒๒** ให้การดำเนินการตามระเบียบมหาวิทยาลัยธรรมศาสตร์ว่าด้วยเงินกองทุนอุดหนุนกิจกรรมนักศึกษา พ.ศ. ๒๕๕๙ อยู่ก่อนวันที่ข้อบังคับนี้มีผลใช้บังคับให้ดำเนินการตามระเบียบเดิมต่อไปจนกว่าจะแล้วเสร็จ

ประกาศ ณ วันที่ ๓๐ เดือน สิงหาคม พ.ศ. ๒๕๖๔

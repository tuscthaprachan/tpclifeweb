# ระเบียบกิจกรรมนักศึกษามหาวิทยาลัยธรรมศาสตร์

## ว่าด้วยการดำเนินงานและการประชุมสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์ พ.ศ. 2569

---

<a id="clause-1"></a>**ข้อ 1** ระเบียบนี้เรียกว่า “ระเบียบกิจการนักศึกษามหาวิทยาลัยธรรมศาสตร์ ว่าด้วยการดำเนินงานและการประชุมสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์ พ.ศ. 2569”

<a id="clause-2"></a>**ข้อ 2** ระเบียบนี้บังคับใช้นับตั้งแต่วันที่สภามีมติเห็นชอบเป็นต้นไป

<a id="clause-3"></a>**ข้อ 3** ในระเบียบนี้

“สภา” หมายความว่า สภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

“ประธานสภา” หมายความว่า ประธานสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

“รองประธานสภา” หมายความว่า รองประธานสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

“เลขาธิการ” หมายความว่า เลขาธิการสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

“รองเลขาธิการ” หมายความว่า รองเลขาธิการสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

“สมาชิก” หมายความว่า สมาชิกสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

“ประธาน” หมายความว่า ประธานในที่ประชุมของสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

“กรรมาธิการ” หมายความว่า กรรมาธิการสามัญหรือกรรมาธิการวิสามัญของสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

“สำนักประธานสภา” หมายความว่า สำนักประธานสภาของสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

<!-- page 2 -->
“สำนักเลขาธิการ” หมายความว่า สำนักเลขาธิการของสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

“อนุกรรมาธิการ” หมายความว่า บุคคลซึ่งคณะกรรมาธิการแต่งตั้งขึ้น เพื่อช่วยเหลือกิจการใด ๆ ของคณะกรรมาธิการ

“การประชุม” หมายความว่า การประชุมของสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

“ที่ประชุม” หมายความว่า ที่ประชุมของสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

“บริเวณสภา” หมายความว่า อาณาบริเวณอันเป็นขอบเขตรับผิดชอบของสภา สถานที่สำหรับใช้ในการประชุมทั้งเป็นการถาวรหรือเป็นการชั่วคราว สำนักงานของคณะกรรมการบริหารสภา คณะกรรมาธิการ สำนักประธานสภา สำนักเลขาธิการและสมาชิก และให้หมายความรวมถึง บัญชีผู้ใช้ ห้องสนทนา ห้องประชุม และอื่น ๆ ของสภา ซึ่งอาศัยผ่านทางสื่ออิเล็กทรอนิกส์ด้วย

“พรรค” หมายความว่า พรรคนักศึกษาที่มีที่นั่งในสภา

“มหาวิทยาลัย” หมายความว่า มหาวิทยาลัยธรรมศาสตร์

“ข้อบังคับ” หมายความว่า ข้อบังคับมหาวิทยาลัยธรรมศาสตร์ ว่าด้วยกิจกรรมนักศึกษามหาวิทยาลัยธรรมศาสตร์ พ.ศ. 2563

<a id="clause-4"></a>**ข้อ 4** ให้ประธานสภารักษาการตามระเบียบนี้ และมีอำนาจออกระเบียบเพื่อปฏิบัติการตามระเบียบนี้

## หมวด 1 คณะกรรมการประสานงานร่วมสภา

<a id="clause-5"></a>**ข้อ 5** ให้มีคณะกรรมการคณะหนึ่งเรียกว่า “คณะกรรมการประสานงานร่วมสภา” ประกอบด้วยประธานสภาหรือรองประธานสภาที่ประธานสภามอบหมายเป็นประธานคณะกรรมการ และกรรมการอื่นอีกไม่เกินเก้าคน ซึ่งประธานสภาแต่งตั้งจากสมาชิกพรรคอย่างน้อยจำนวนหนึ่งคนต่อหนึ่งพรรค ตามมติของแต่ละพรรค

<!-- page 3 -->
ในกรณีที่สภาประกอบไปด้วยพรรคเพียงหนึ่งพรรค อาจไม่ต้องแต่งตั้งคณะกรรมการโดยอนุโลม

<a id="clause-6"></a>**ข้อ 6** กรรมการประสานงานร่วมสภาพ้นจากตำแหน่ง เมื่อ

1. (1) สภาสิ้นอายุหรือสภาถูกยุบ
2. (2) ตาย
3. (3) ลาออก
4. (4) พ้นจากการเป็นสมาชิก
5. (5) มีการแต่งตั้งคณะกรรมการประสานงานร่วมสภาคณะใหม่แทนคณะเดิม

<a id="clause-7"></a>**ข้อ 7** คณะกรรมการประสานงานร่วมสภามีอำนาจและหน้าที่ ดังต่อไปนี้

1. (1) พิจารณาดำเนินการหรือประสานงานในเรื่องที่เกี่ยวข้องกับการประชุมและกิจการของสภา
2. (2) หน้าที่และอำนาจอื่นตามที่ประธานสภามอบหมาย

## หมวด 2 การประชุม

### ส่วนที่ 1 วิธีการประชุม

<a id="clause-8"></a>**ข้อ 8** การประชุมย่อมเป็นการเปิดเผย นักศึกษาทั่วไปสามารถเข้าร่วมสังเกตการณ์การประชุมบริเวณสภาได้ตามที่ประธานประกาศ เว้นแต่สมาชิกจำนวนเกินกว่ากึ่งหนึ่งของจำนวนสมาชิกทั้งหมดเท่าที่มีอยู่ของสภาร้องขอให้ประชุมลับ ก็ให้ประชุมลับ

การประชุมลับ ห้ามบุคคลภายนอกเข้ารับฟังการประชุม เว้นแต่ผู้ที่ได้รับอนุญาตจากประธานเท่านั้น

<!-- page 4 -->
<a id="clause-9"></a>**ข้อ 9** กรณีมีเหตุอันจำเป็นให้เรียกประชุม นอกเหนือจากการประชุมสมัยสามัญ ประธานสภาอาจให้เรียกประชุมสมัยวิสามัญได้

<a id="clause-10"></a>**ข้อ 10** การนัดหมายประชุมต้องทำเป็นหนังสือแจ้งวัน เวลา สถานที่ และระเบียบวาระการประชุม ให้สมาชิกทราบล่วงหน้าไม่น้อยกว่าห้าวันสำหรับการประชุมสมัยสามัญ และไม่น้อยกว่าสามวันสำหรับการประชุมสมัยวิสามัญ

หากมีเหตุจำเป็นเร่งด่วนอันหลีกเลี่ยงมิได้ ให้ประธานสภาวินิจฉัยเพื่อการนัดหมายประชุมล่วงหน้าอย่างน้อยหนึ่งชั่วโมง

<a id="clause-11"></a>**ข้อ 11** ให้เลขาธิการส่งระเบียบวาระการประชุมและเอกสารที่เกี่ยวข้องไปพร้อมกับหนังสือนัดหมายประชุม หากประธานสภาเห็นสมควร จะบรรจุเรื่องใดเพิ่มเติมในระเบียบวาระการประชุมอีกก็ได้ แต่ต้องก่อนวันประชุมไม่น้อยกว่าหนึ่งวัน

<a id="clause-12"></a>**ข้อ 12** การนัดหมายประชุมตามข้อ 10 และการส่งเอกสารตามข้อ 11 อาจดำเนินการผ่านสื่ออิเล็กทรอนิกส์หรือสื่อเทคโนโลยีสารสนเทศประเภทอื่นเพิ่มเติมด้วยก็ได้ เมื่อประธานสภาเห็นสมควร เว้นแต่การจัดส่งเอกสารลับ ให้เป็นไปตามที่ประธานสภากำหนด

<a id="clause-13"></a>**ข้อ 13** การจัดระเบียบวาระการประชุมให้จัดลำดับ ดังต่อไปนี้

1. (1) กระทู้ถาม
2. (2) เรื่องที่ประธานแจ้งให้ทราบ
3. (3) รับรองรายงานการประชุม
4. (4) เรื่องที่คณะกรรมาธิการพิจารณาเสร็จแล้ว
5. (5) เรื่องที่สืบเนื่องจากครั้งก่อน
6. (6) เรื่องที่เสนอให้ที่ประชุมพิจารณา
7. (7) เรื่องอื่น ๆ
8. (8) กำหนดการประชุมสภาครั้งต่อไป

<!-- page 5 -->
ในกรณีที่ประธานสภาเห็นว่าเรื่องใดเป็นเรื่องด่วน จะจัดไว้ในลำดับใดของระเบียบวาระการประชุมก็ได้ แต่จะจัดไว้ก่อนเรื่องที่คณะกรรมาธิการพิจารณาเสร็จแล้วไม่ได้ เว้นแต่จะเป็นการเรียกนายกองค์การนักศึกษา อุปนายกองค์การนักศึกษา ผู้ได้รับมอบหมายให้ปฏิบัติหน้าที่แทน หรือบุคคลอื่นให้เข้ามาชี้แจง หรือรายงานผลการดำเนินงาน ประธานสภาอาจจัดไว้ใน (1) ก็ได้

การตั้งกระทู้ถามคณะกรรมการบริหารสภาหรือกรรมการบริหารสภาสามารถกระทำได้ และให้ไว้ใน (1) โดยจะต้องเสนอกระทู้นั้นต่อประธานสภาก่อนวันประชุมอย่างน้อยหนึ่งวัน โดยผู้ถูกตั้งกระทู้ถามอาจตอบหรือไม่ก็ได้

กรณีการตั้งกระทู้ถามสดด้วยวาจาซึ่งเสนอในที่ประชุม จะต้องเป็นเรื่องที่เกี่ยวข้องกับผลประโยชน์ของมหาวิทยาลัย นักศึกษา สภา หรือเรื่องสำคัญเร่งด่วน และไม่เป็นคำถามในลักษณะที่เป็นการโจมตีตัวบุคคลหรือกลุ่มบุคคล

คำวินิจฉัยของประธานเกี่ยวกับการตั้งกระทู้ตามวรรคสามและวรรคสี่ ให้ถือเป็นเด็ดขาด

<a id="clause-14"></a>**ข้อ 14** ก่อนเข้าสู่ระเบียบวาระการประชุม ประธานอาจอนุญาตให้สมาชิกปรึกษาหารือปัญหาที่เกี่ยวกับความเดือดร้อนของนักศึกษาหรือปัญหาอื่นใดได้ ตามหลักเกณฑ์และวิธีการที่ประธานสภากำหนด และให้ประธานสภาส่งเรื่องดังกล่าวให้หน่วยงานของมหาวิทยาลัยที่เกี่ยวข้องมาชี้แจงภายในเวลาการประชุมครั้งต่อไป และแจ้งให้สมาชิกทราบ

<a id="clause-15"></a>**ข้อ 15** ก่อนเข้าประชุมทุกครั้ง ให้สมาชิกที่มาประชุมลงชื่อในเอกสารแบบลงชื่อประเภทอื่น ๆ หรือแสดงตนตามระเบียบที่ประธานสภากำหนด เมื่อสมาชิกลงชื่อมาประชุมไม่น้อยกว่ากึ่งหนึ่งของจำนวนสมาชิกทั้งหมดเท่าที่มีอยู่จึงจะเป็นองค์ประชุม

เมื่อสมาชิกลงชื่อครบองค์ประชุมและมีสัญญาณให้เข้าประชุมแล้ว หลังจากนั้นภายในห้านาที ให้ประธานดำเนินการประชุม

<a id="clause-16"></a>**ข้อ 16** หากสมาชิกไม่กระทำตามข้อ 15 วรรคหนึ่ง โดยไม่มีการแจ้งให้ประธานสภาหรือเลขาธิการทราบล่วงหน้า จะถือให้สมาชิกขาดประชุม

<!-- page 6 -->
หากสมาชิกเข้าประชุมหรือออกจากที่ประชุมในระหว่างที่การประชุมกำลังดำเนินอยู่ ให้แจ้งต่อประธานหรือเลขาธิการทราบทันที ในทุกกรณี

เมื่อประธานมีสัญญาณให้เริ่มการประชุม ให้ทุกคนในที่ประชุมอยู่ในความสงบเรียบร้อย

<a id="clause-17"></a>**ข้อ 17** เมื่อพ้นกำหนดประชุมไปสามสิบนาทีแล้ว หากจำนวนสมาชิกยังไม่ครบองค์ประชุม ประธานจะสั่งให้เลื่อนการประชุมไปก็ได้

<a id="clause-18"></a>**ข้อ 18** ในการประชุมนั้น ให้ที่ประชุมพิจารณาเฉพาะเรื่องที่มีอยู่ในระเบียบวาระการประชุมและต้องดำเนินการพิจารณาตามลำดับระเบียบวาระการประชุมที่จัดไว้ เว้นแต่ที่ประชุมจะลงมติเป็นอย่างอื่น โดยต้องมีมติเห็นชอบไม่น้อยกว่าหนึ่งในสามขององค์ประชุม

<a id="clause-19"></a>**ข้อ 19** ผู้ใดประสงค์จะกล่าวถ้อยคำต่อที่ประชุม ให้ยกมือขึ้นพ้นศีรษะ เมื่อประธานอนุญาตแล้วจึงกล่าวได้ และต้องเป็นคำกล่าวต่อประธานเท่านั้น

หากมีเหตุจำเป็นต้องขานชื่อสมาชิกคนอื่น ผู้กล่าวจะต้องกล่าวว่า “ขออนุญาตเอ่ยนาม” ทุกครั้ง

ในการประชุมผ่านสื่ออิเล็กทรอนิกส์ ให้ประธานกำหนดหลักเกณฑ์และวิธีการแสดงความประสงค์จะกล่าวถ้อยคำต่อที่ประชุมของสมาชิกตามสมควร

<a id="clause-20"></a>**ข้อ 20** ประธานอาจปรึกษาหารือที่ประชุมในปัญหาใด ๆ กำหนดวิธีการตรวจสอบองค์ประชุม สั่งพักการประชุม เลื่อนการประชุม หรือเลิกการประชุมได้ตามที่เห็นสมควร

หากประธานออกจากที่ประชุมโดยมิได้มีการสั่งการแต่อย่างใด และไม่มีผู้ใดปฏิบัติหน้าที่แทน ให้เลิกการประชุม โดยให้มีการบันทึกไว้และให้ประธานชี้แจงต่อสมาชิกถึงการออกจากที่ประชุมของประธาน

<a id="clause-21"></a>**ข้อ 21** รายงานการประชุม ให้เลขาธิการเป็นผู้จัดทำและผู้ตรวจทาน

เมื่อเลขาธิการตรวจแล้ว ก่อนที่จะเสนอให้สภารับรอง ให้ทำสำเนาวางไว้ ณ บริเวณสภา หรือส่งสำเนาผ่านทางสื่ออิเล็กทรอนิกส์หรือสื่อเทคโนโลยีสารสนเทศอื่น ๆ ไม่น้อยกว่าสามวัน หรือด้วยวิธีการอื่นตามแต่ประธานจะเห็นสมควร เพื่อให้สมาชิกตรวจดูได้

<!-- page 7 -->
รายงานการประชุมทุกครั้งจะต้องมีรายชื่อสมาชิกที่มาประชุม ที่ลาการประชุม ที่ขาดประชุม ผู้เข้าสังเกตการณ์การประชุม และบันทึกการออกเสียงลงคะแนน

สมาชิกมีสิทธิขอแก้ไขเพิ่มเติมรายงานการประชุมดังกล่าวให้ตรงตามที่เป็นจริง โดยยื่นคำขอแก้ไขเพิ่มเติมต่อเลขาธิการ ถ้าเลขาธิการไม่ดำเนินการแก้ไขเพิ่มเติมให้ตามที่ขอ สมาชิกผู้นั้นมีสิทธิที่จะยืนยันคำขอแก้ไข โดยขอให้สภาวินิจฉัยและต้องมีมติรับรองให้แก้ไขไม่น้อยกว่าหนึ่งในห้าขององค์ประชุม

<a id="clause-22"></a>**ข้อ 22** รายงานการประชุมครั้งใด เมื่อได้วางสำเนาไว้หรือส่งให้เพื่อให้สมาชิกตรวจดูแล้ว ถ้ามีการแก้ไขเพิ่มเติมในภายหลังโดยคณะกรรมาธิการแก้ไขเพิ่มเติมเองหรือโดยสมาชิกขอแก้ไขเพิ่มเติมก็ตาม ในคราวที่สภาพิจารณารับรองรายงานประชุมนั้น คณะกรรมาธิการหรือเลขาธิการจะต้องแถลงต่อที่ประชุมถึงการแก้ไขเพิ่มเติมดังกล่าว

<a id="clause-23"></a>**ข้อ 23** เมื่อสภาได้รับรองรายงานการประชุมครั้งใดแล้ว ให้ประธานสภาลงลายมือชื่อไว้เป็นหลักฐาน

รายงานการประชุมที่ได้รับรองแล้ว แต่ประธานยังมิได้ลงลายมือชื่อไว้เป็นหลักฐาน หรือรายงานการประชุมที่ยังมิได้มีการรับรองเพราะเหตุที่อายุของสภาสิ้นสุดลง ให้เลขาธิการบันทึกเหตุนั้นไว้ และเป็นผู้รับรองความถูกต้องของรายงานการประชุมนั้น

<a id="clause-24"></a>**ข้อ 24** สภาอาจมีมติไม่ให้จดรายงานการประชุมลับครั้งใดทั้งหมด หรือแต่เพียงบางส่วนก็ได้แต่ให้มีบันทึกเหตุการณ์ไว้

<a id="clause-25"></a>**ข้อ 25** การเปิดเผยรายงานการประชุมลับ ให้ที่ประชุมพิจารณาและมีมติจะเปิดเผยหรือไม่ โดยต้องมีมติเห็นชอบไม่น้อยกว่ากึ่งหนึ่งของสมาชิกเท่าที่มีอยู่ของสภา จึงจะเปิดเผยได้

<a id="clause-26"></a>**ข้อ 26** ให้เลขาธิการเป็นผู้พิมพ์และเผยแพร่รายงานการประชุม ทั้งนี้ นอกจากการรายงานการประชุมลับที่สภามีมติไม่ให้เปิดเผย

<!-- page 8 -->
### ส่วนที่ 2 การเสนอญัตติ

<a id="clause-27"></a>**ข้อ 27** ญัตติ คือ ข้อเสนอใด ๆ ที่มีความมุ่งหมายให้สภาลงมติหรือชี้ขาดว่าจะให้ปฏิบัติ หรือดำเนินการอย่างไรต่อไป

<a id="clause-28"></a>**ข้อ 28** ญัตติทั้งหลายต้องเสนอล่วงหน้าเป็นหนังสือต่อประธานสภา และต้องมีจำนวนสมาชิกรับรองไม่น้อยกว่าสามคน ทั้งนี้ เว้นแต่ระเบียบนี้ได้กำหนดไว้โดยเฉพาะให้เป็นอย่างอื่น

<a id="clause-29"></a>**ข้อ 29** ญัตติขอให้สภาตั้งคณะกรรมาธิการหรือขอให้คณะกรรมาธิการคณะใดคณะหนึ่งกระทำกิจการ พิจารณา สอบสวน หรือศึกษาเรื่องใด ๆ อันอยู่ในอำนาจหน้าที่ของสภา ถ้าสมาชิกเป็นผู้เสนอ ต้องมีจำนวนสมาชิกรับรองไม่น้อยกว่าหนึ่งในสี่ของจำนวนสมาชิกทั้งหมดเท่าที่มีอยู่ของสภา

<a id="clause-30"></a>**ข้อ 30** ญัตติขอให้กรรมการบริหารสภาพ้นจากตำแหน่ง ต้องมีจำนวนสมาชิกรับรองไม่น้อยกว่าหนึ่งในสี่ของจำนวนสมาชิกทั้งหมดเท่าที่มีอยู่ของสภา

<a id="clause-31"></a>**ข้อ 31** ญัตติขอให้กรรมาธิการพ้นจากตำแหน่ง ต้องมีคณะกรรมาธิการ หรือสำนักที่สังกัดเสนอประกอบการระบุเหตุผลอันเป็นที่ประจักษ์ลงในหนังสือต่อประธานสภา

<a id="clause-32"></a>**ข้อ 32** ในกรณีที่เกี่ยวกับประโยชน์สำคัญของมหาวิทยาลัยหรือนักศึกษา หรือมีความจำเป็นเร่งด่วนอันเกี่ยวข้องกับสิทธิและสวัสดิการของนักศึกษา สมาชิกจะเสนอญัตติด่วนเพื่อให้สภาพิจารณาเป็นการด่วนก็ได้ ญัตติด่วนต้องไม่มีลักษณะทำนองเดียวกับกระทู้ และต้องมีวัตถุประสงค์เพื่อให้สภาดำเนินการอย่างใดอย่างหนึ่งด้วย

<a id="clause-33"></a>**ข้อ 33** ให้เป็นอำนาจของประธานสภาที่จะวินิจฉัยว่าญัตติใดเป็นญัตติด่วนหรือไม่ และเมื่อวินิจฉัยแล้ว ให้แจ้งผู้เสนอญัตติทราบพร้อมด้วยเหตุผลภายในสามวันนับแต่วันที่ได้รับญัตตินั้น

ให้ประธานสภาบรรจุญัตติด่วนเข้าระเบียบวาระประชุมเป็นเรื่องด่วน

ญัตติที่ประธานสภาวินิจฉัยว่าไม่ได้เป็นญัตติด่วน ให้ประธานสภาดำเนินการต่อไปตามข้อ 34

<!-- page 9 -->
<a id="clause-34"></a>**ข้อ 34** ภายใต้บังคับข้อ 33 ให้ประธานสภาบรรจุญัตติเข้าระเบียบวาระการประชุมภายในเจ็ดวัน นับแต่วันที่ได้รับญัตตินั้นตามลำดับที่ยื่นก่อนหลัง กำหนดวันดังกล่าวให้หมายถึงวันในสมัยประชุม

<a id="clause-35"></a>**ข้อ 35** ญัตติต่อไปนี้ไม่ต้องเสนอล่วงหน้าหรือเป็นหนังสือ

1. (1) ขอให้พิจารณาเป็นเรื่องด่วน
2. (2) ขอเปลี่ยนระเบียบวาระการประชุม
3. (3) ญัตติที่ประธานอนุญาตตามที่เห็นสมควร

<a id="clause-36"></a>**ข้อ 36** เมื่อที่ประชุมกำลังพิจารณาญัตติใดอยู่ ห้ามเสนอญัตติอื่นมาพิจารณา เว้นแต่ญัตติ ดังต่อไปนี้

1. (1) ขอให้รวมระเบียบวาระการประชุมเป็นเรื่องเดียวกัน ทำนองเดียวกัน หรือเกี่ยวเนื่องกันเพื่อพิจารณาพร้อมกัน
2. (2) ขอให้ส่งปัญหาไปยังคณะกรรมาธิการเพื่อพิจารณา หรือขอให้บุคคลใดส่งเอกสารหรือมาแถลงข้อเท็จจริงหรือแสดงความคิดเห็น
3. (3) ขอให้รวมหรือแยกประเด็นพิจารณาหรือลงมติ
4. (4) ขอให้เลื่อนการปรึกษาหรือพิจารณา
5. (5) ขอให้ปิดอภิปราย
6. (6) ขอให้ยกเรื่องอื่นขึ้นปรึกษาหรือพิจารณา

<a id="clause-37"></a>**ข้อ 37** ญัตติตามข้อ 36 (5) และ (6) ห้ามเสนอในคราวเดียวกับการอภิปรายของตน

<a id="clause-38"></a>**ข้อ 38** ในกรณีที่ที่ประชุมลงมติให้ยกเรื่องอื่นขึ้นปรึกษาหรือพิจารณา ให้ญัตติเดิมเป็นอันตกไป

<a id="clause-39"></a>**ข้อ 39** ญัตติที่เสนอล่วงหน้าเป็นหนังสือ ให้ผู้รับรองญัตติแสดงการรับรองโดยวิธียกมือขึ้นพ้นศีรษะ

ในการประชุมผ่านสื่ออิเล็กทรอนิกส์ ให้ผู้รับรองญัตติแสดงการรับรองตามหลักเกณฑ์และวิธีการที่ประธานกำหนด

<!-- page 10 -->
นักศึกษาไม่น้อยกว่า 25 คน สามารถเสนอญัตติอันเกี่ยวข้องกับประเด็นความเดือดร้อนหรือปัญหาใด ๆ ให้สภาพิจารณา ทั้งนี้วิธีการและรูปแบบการเสนอญัตติให้เป็นไปตามประกาศที่ประธานสภากำหนด

<a id="clause-40"></a>**ข้อ 40** ญัตติที่บรรจุเข้าระเบียบวาระการประชุมแล้ว หากผู้เสนอญัตติจะถอนญัตติหรือจะแก้ไขเพิ่มเติมหรือจะถอนชื่อจากการเป็นผู้ร่วมกันเสนอ หรือผู้รับรองจะถอนการรับรองญัตติจะต้องได้รับความยินยอมของที่ประชุม

<a id="clause-41"></a>**ข้อ 41** ญัตติใดถึงวาระพิจารณาในที่ประชุมแล้ว การเสนอญัตติซึ่งมีหลักการเดียวกันจะกระทำมิได้ ถ้าผู้เสนอญัตติหรือผู้แปรญัตติไม่ชี้แจงในที่ประชุม หรือผู้เสนอญัตติหรือผู้แปรญัตติไม่อยู่ในที่ประชุมโดยไม่มีผู้ชี้แจงแทนในฐานะผู้มอบหมาย ญัตติหรือคำแปรญัตตินั้นเป็นอันตกไป

การมอบหมายให้ชี้แจงแทนต้องทำเป็นหนังสือยื่นต่อประธานสภา

<a id="clause-42"></a>**ข้อ 42** ญัตติใดตกไปแล้ว ห้ามนำญัตติซึ่งมีหลักการเช่นเดียวกันขึ้นเสนออีกในสมัยประชุมเดียวกัน เว้นแต่ญัตติที่ยังไม่ได้มีการลงมติหรือญัตติที่ประธานสภาอนุญาตเมื่อพิจารณาเห็นว่าเหตุการณ์ได้เปลี่ยนแปลงไป

<a id="clause-43"></a>**ข้อ 43** ญัตติใดที่บรรจุเข้าระเบียบวาระการประชุมแล้ว หากสภาไม่ได้พิจารณาในสมัยประชุมนั้นให้เป็นอันตกไป

### ส่วนที่ 3 การอภิปราย

<a id="clause-44"></a>**ข้อ 44** ผู้มีสิทธิอภิปรายก่อน คือ ผู้เสนอญัตติหรือผู้แปรญัตติ ในกรณีผู้เสนอญัตติหรือผู้แปรญัตติมีหลายคน ให้ประธานอนุญาตให้อภิปรายก่อนได้เพียงคนเดียว

กรรมาธิการซึ่งได้สงวนความเห็น กรรมาธิการผู้รับมอบหมายจากกรรมาธิการซึ่งได้สงวนความเห็น หรือกรรมาธิการผู้รับมอบหมายจากผู้แปรญัตติซึ่งได้สงวนคำแปรญัตติในชั้นคณะกรรมาธิการ ให้มีฐานะเสมือนเป็นผู้แปรญัตติด้วย

<!-- page 11 -->
<a id="clause-45"></a>**ข้อ 45** ถ้ามีผู้อภิปรายหลายคน ประธานจะให้คนใดอภิปรายก็ได้ แต่ให้คำนึงถึงผู้เสนอญัตติ ผู้แปรญัตติ และผู้ซึ่งยังไม่ได้อภิปรายด้วย

<a id="clause-46"></a>**ข้อ 46** การอภิปรายต้องอยู่ในประเด็นหรือเกี่ยวกับประเด็นที่กำลังปรึกษากันอยู่ ต้องไม่ฟุ่มเฟือย วนเวียน ซ้ำซากหรือซ้ำกับผู้อื่น และห้ามไม่ให้นำเอกสารใด ๆ มาอ่านให้ที่ประชุมฟังโดยไม่จำเป็น และห้ามไม่ให้นำวัตถุใด ๆ เข้ามาแสดงในที่ประชุม เว้นแต่ประธานอนุญาต

ห้ามผู้อภิปรายแสดงกิริยาหรือใช้วาจาอันไม่สุภาพ และห้ามกล่าวถึงสมาชิกหรือบุคคลใดโดยไม่จำเป็น

<a id="clause-47"></a>**ข้อ 47** ถ้าประธานเห็นว่าผู้ใดได้อภิปรายพอสมควรแล้ว ประธานจะให้ผู้นั้นหยุดอภิปรายก็ได้

<a id="clause-48"></a>**ข้อ 48** สมาชิกผู้ใดต้องการประท้วงว่ามีการฝ่าฝืนข้อบังคับหรือระเบียบนี้ ให้ทำการยกมือขึ้นพ้นศีรษะ โดยที่ประธานต้องให้โอกาสผู้นั้นชี้แจง แล้วให้ประธานวินิจฉัยว่าได้มีการฝ่าฝืนข้อบังคับหรือระเบียบนี้ ตามที่ประท้วงหรือไม่

ในการประชุมผ่านสื่ออิเล็กทรอนิกส์ ให้สมาชิกแสดงความต้องการประท้วงว่ามีการฝ่าฝืนข้อบังคับหรือระเบียบนี้ ตามหลักเกณฑ์และวิธีการที่ประธานกำหนด

ให้นำความในวรรคหนึ่งและวรรคสองมาใช้บังคับโดยอนุโลมแก่ผู้ถูกอภิปรายพาดพิงถึงเรื่องส่วนตัวหรืออื่นใดอันเป็นที่เสียหายแก่ผู้นั้น และให้หมายความรวมถึงการถูกขานชื่อตามข้อ 19 วรรคสอง

<a id="clause-49"></a>**ข้อ 49** เมื่อมีผู้ประท้วงตามข้อ 48 ผู้อภิปรายอาจถอนคำพูดของตนหรือตามคำวินิจฉัยของประธาน ถ้าผู้อภิปรายออกไปจากที่ประชุมสภาโดยไม่ถอนคำพูดตามคำวินิจฉัยของประธาน ให้เลขาธิการบันทึกการไม่ปฏิบัติตามคำวินิจฉัยไว้ในรายงานการประชุม

<a id="clause-50"></a>**ข้อ 50** การอภิปรายเป็นอันยุติ เมื่อ

1. (1) ไม่มีผู้ใดอภิปราย
2. (2) ที่ประชุมลงมติให้ปิดอภิปราย
3. (3) ที่ประชุมลงมติให้ยกเรื่องอื่นขึ้นปรึกษา

<!-- page 12 -->
<a id="clause-51"></a>**ข้อ 51** ในกรณีที่ประธานพิจารณาเห็นว่าได้อภิปรายกันพอสมควรแล้ว จะขอให้ที่ประชุมวินิจฉัยว่าปิดอภิปรายหรือไม่ก็ได้

<a id="clause-52"></a>**ข้อ 52** เมื่อการอภิปรายได้ยุติแล้ว ห้ามผู้ใดอภิปรายอีก เว้นแต่ที่ประชุมจะต้องลงมติในเรื่องนั้น จึงให้ผู้ซึ่งมีสิทธิอภิปรายก่อนคนใดคนหนึ่งในแต่ละญัตติ มีสิทธิอภิปรายสรุปได้อีกครั้งหนึ่งเป็นครั้งสุดท้ายก่อนที่ประชุมจะลงมติ

<a id="clause-53"></a>**ข้อ 53** ถ้าประธานให้สัญญาณด้วยการเคาะค้อนหรือยืนขึ้นหรือวิธีการอื่นใดตามสมควร ให้ผู้ที่กำลังพูดหยุดพูดและนั่งลงทันที

### ส่วนที่ 4 การลงมติ

<a id="clause-54"></a>**ข้อ 54** ในกรณีที่จะต้องมีมติของสภา ให้ประธานมีสัญญาณให้สมาชิกทราบก่อนลงมติ

<a id="clause-55"></a>**ข้อ 55** เสียงข้างมากนั้น หากความเห็นของที่ประชุมมีตั้งแต่สองฝ่ายขึ้นไป ให้ถือเอาจำนวนคะแนนเสียงฝ่ายที่มากที่สุด

ในกรณีที่คะแนนเสียงเท่ากัน ประธานอาจให้ทำการลงมติใหม่ก็ได้ หรือให้ประธานกำหนดวิธีการลงมติในรูปแบบอื่น โดยต้องมีสมาชิกรับรองไม่น้อยกว่าสองในสามขององค์ประชุมในกรณีที่มีการลงมติในรูปแบบอื่น

ให้นำความในวรรคสองมาบังคับใช้ก่อน หากการลงมติครั้งที่สองคะแนนเสียงเท่ากัน ให้ประธานเป็นผู้ชี้ขาด

<a id="clause-56"></a>**ข้อ 56** การออกเสียงลงคะแนนให้กระทำเป็นการเปิดเผย แต่เมื่อสมาชิกเสนอญัตติโดยมีผู้รับรองไม่น้อยกว่าสองในสามขององค์ประชุมขอให้กระทำเป็นการลับ จึงให้ลงคะแนนลับ

ในกรณีที่สมาชิกเสนอญัตติให้ลงคะแนนลับตามวรรคหนึ่ง ถ้ามีสมาชิกคัดค้านและมีผู้รับรองไม่น้อยกว่าหนึ่งในสามขององค์ประชุม ให้ถือเป็นเอกสิทธิ์ที่จะลงคะแนนโดยเปิดเผย

การออกเสียงลงคะแนนจะกระทำแทนกันมิได้

<!-- page 13 -->
<a id="clause-57"></a>**ข้อ 57** การออกเสียงลงคะแนนโดยเปิดเผยมีวิธีปฏิบัติ ดังต่อไปนี้

1. (1) ทำการยกมือขึ้นพ้นศีรษะ
2. (2) แสดงการออกเสียงแบบระบุตัวตนผ่านสื่ออิเล็กทรอนิกส์ ตามที่ประธานกำหนด
3. (3) วิธีการอื่นใดซึ่งที่ประชุมเห็นสมควรเฉพาะกรณี

การออกเสียงลงคะแนนตาม (2) หากสื่ออิเล็กทรอนิกส์ขัดข้องให้เปลี่ยนวิธีการตามที่ประธานกำหนด

การออกเสียงลงคะแนนให้ใช้วิธีตาม (1) จะใช้วิธีตาม (2) หรือ (3) ได้ต่อเมื่อสมาชิกเสนอญัตติและที่ประชุมอนุมัติ หรือมีการประชุมผ่านสื่ออิเล็กทรอนิกส์ หรือเมื่อมีการนับคะแนนเสียงใหม่ตามข้อ 59

การออกเสียงลงคะแนนตามวรรคสอง กรณีที่ประธานเห็นสมควร ให้ประธานเชิญสมาชิกไม่น้อยกว่าสามคนเป็นผู้ตรวจนับคะแนน

<a id="clause-58"></a>**ข้อ 58** การออกเสียงลงคะแนนลับมีวิธีปฏิบัติ ดังต่อไปนี้

1. (1) เขียนเครื่องหมายบนแผ่นกระดาษ แล้วพับปิดอย่างมิดชิด โดยผู้เห็นชอบให้เขียนว่า “เห็นชอบ” ผู้ไม่เห็นชอบให้เขียนว่า “ไม่เห็นชอบ” ส่วนผู้ไม่ออกเสียงให้เขียนว่า “งดออกเสียง”
2. (2) แสดงการออกเสียงแบบไม่ระบุตัวตนผ่านสื่ออิเล็กทรอนิกส์ตามที่ประธานกำหนด
3. (3) วิธีการอื่นใดซึ่งที่ประชุมเห็นสมควรเฉพาะกรณี

ให้นำความในข้อ 57 วรรคสอง วรรคสามและวรรคสี่ มาใช้บังคับโดยอนุโลม

<a id="clause-59"></a>**ข้อ 59** เมื่อมีการออกเสียงลงคะแนนตามข้อ 57 (1) แล้ว ถ้าสมาชิกร้องขอให้มีการนับใหม่ โดยมีผู้รับรองไม่น้อยกว่าสิบคน ก็ให้มีการนับคะแนนเสียงใหม่โดยกระทำตามเดิมได้อีกหนึ่งครั้ง

ถ้าสมาชิกร้องขอให้มีการนับใหม่เป็นครั้งที่สอง โดยมีผู้รับรองไม่น้อยกว่าสิบคน ให้เปลี่ยนวิธีการลงคะแนนเป็นวิธีตามข้อ 57 (2) หรือ (3) เว้นแต่คะแนนเสียงต่างกันเกินกว่าห้าคะแนนจะขอให้มีการนับคะแนนเสียงใหม่ไม่ได้

<!-- page 14 -->
<a id="clause-60"></a>**ข้อ 60** ญัตติใดไม่มีผู้คัดค้าน ให้ประธานถามที่ประชุมว่ามีผู้เห็นเป็นอย่างอื่นหรือไม่ เมื่อไม่มีผู้เห็นเป็นอย่างอื่น ให้ถือว่าที่ประชุมลงมติเห็นชอบด้วยญัตตินั้น

ให้เลขาธิการจัดทำบันทึกการออกเสียงลงคะแนนของสมาชิกสภารายบุคคลและเปิดเผยบันทึกดังกล่าวไว้ในรายงานการประชุม หรือสื่ออิเล็กทรอนิกส์หรือสื่อเทคโนโลยีสารสนเทศประเภทอื่น เพื่อให้นักศึกษาและประชาคมธรรมศาสตร์ทราบได้ทั่วไป เว้นแต่การออกเสียงลงคะแนนเป็นการลับตามข้อ 58

## หมวด 3 กรรมาธิการ

<a id="clause-61"></a>**ข้อ 61** คณะกรรมาธิการสามัญจะมีขึ้นได้ด้วยความเห็นชอบจากสมาชิกเกินกึ่งหนึ่งของจำนวนสมาชิกทั้งหมดเท่าที่มีอยู่ของสภา

สมาชิกคนหนึ่งจะต้องสังกัดคณะกรรมาธิการสามัญอย่างน้อยหนึ่งคณะ โดยที่สำนักประธานสภาและสำนักเลขาธิการมีศักดิ์เทียบเท่าคณะกรรมาธิการสามัญ

<a id="clause-62"></a>**ข้อ 62** การตั้งคณะกรรมาธิการวิสามัญ สามารถกระทำได้ เพื่อดำเนินการเฉพาะเรื่องใดเรื่องหนึ่ง ซึ่งอยู่นอกเหนืออำนาจหน้าที่ของคณะกรรมาธิการสามัญ หรือตามที่สภาเห็นสมควร

คณะกรรมาธิการวิสามัญสิ้นสุดลงเมื่อการดำเนินการนั้นเสร็จสิ้นแล้ว

<a id="clause-63"></a>**ข้อ 63** การเลือกตั้งประธานคณะกรรมาธิการ ให้เป็นไปตามมติของที่ประชุมสภา

<a id="clause-64"></a>**ข้อ 64** การประชุมคณะกรรมาธิการ สามารถนำระเบียบนี้เฉพาะที่เกี่ยวกับการประชุมสภามาใช้บังคับโดยอนุโลม

ให้ประธานคณะกรรมาธิการแต่ละคณะตั้งรองประธาน เลขานุการ และตำแหน่งอื่นตามความจำเป็นจากกรรมาธิการในคณะนั้น

<!-- page 15 -->
กรณีที่มีการแต่งตั้งกรรมาธิการให้ดำรงตำแหน่งรองประธานมากกว่าหนึ่งคน หรือตำแหน่งอื่นตามวรรคสอง ประธานคณะกรรมาธิการต้องแจ้งให้ประธานสภาและที่ประชุมคณะกรรมาธิการทราบถึงความจำเป็นดังกล่าว

<a id="clause-65"></a>**ข้อ 65** เมื่อไม่มีผู้ดำรงตำแหน่งประธานคณะกรรมาธิการ หรือมีแต่ไม่สามารถปฏิบัติหน้าที่ได้ให้รองประธานคณะกรรมาธิการเป็นผู้ปฏิบัติหน้าที่แทนประธานคณะกรรมาธิการ

ในกรณีที่มีรองประธานคณะกรรมาธิการหลายคน ให้รองประธานคณะกรรมาธิการคนที่หนึ่งเป็นผู้ปฏิบัติหน้าที่แทนประธานคณะกรรมาธิการ หากรองประธานคณะกรรมาธิการคนที่หนึ่งไม่สามารถปฏิบัติหน้าที่ได้ ให้รองประธานคณะกรรมาธิการลำดับต่อไปเป็นผู้ปฏิบัติหน้าที่แทนประธานคณะกรรมาธิการ

ในกรณีที่ไม่มีผู้ปฏิบัติหน้าที่ตามวรรคสอง ให้เลขานุการเป็นผู้ปฏิบัติหน้าที่แทน

ในกรณีไม่มีผู้ปฏิบัติหน้าที่ตามวรรคสองและวรรคสาม ให้กรรมาธิการคนหนึ่งเสนอชื่อกรรมาธิการคนใดเพื่อเป็นผู้ปฏิบัติหน้าที่แทนประธานคณะกรรมาธิการ เมื่อที่ประชุมคณะกรรมาธิการมีมติเห็นชอบด้วยคะแนนเสียงเกินกว่ากึ่งหนึ่งของจำนวนกรรมาธิการเท่าที่มีอยู่

<a id="clause-66"></a>**ข้อ 66** เมื่อมีการเสนอแต่งตั้งอนุกรรมาธิการ ให้มีประกาศสภาหรือประกาศคณะกรรมาธิการเรื่อง การแต่งตั้งอนุกรรมาธิการ ภายในสิบห้าวัน นับตั้งแต่มีการเสนอชื่อ

อนุกรรมาธิการไม่อาจดำรงตำแหน่งตามข้อ 64 วรรคสองได้

อนุกรรมาธิการมีสิทธิเข้าประชุมสภา แต่ไม่มีสิทธิลงคะแนนเสียงในเรื่องต่าง ๆ ของสภาและหากประธานคณะกรรมาธิการหรือประธานเห็นสมควร จะไม่ให้อนุกรรมาธิการเข้าประชุมก็ได้

<a id="clause-67"></a>**ข้อ 67** คณะกรรมาธิการมีอำนาจตั้งคณะอนุกรรมาธิการเพื่อพิจารณาปัญหาอันอยู่ในอำนาจหน้าที่ของคณะกรรมาธิการ และรายงานคณะกรรมาธิการภายในเวลาที่คณะกรรมาธิการกำหนด

ในกรณีที่คณะอนุกรรมาธิการกระทำกิจการ พิจารณาสอบสวน หรือศึกษาเรื่องใดไม่เสร็จในเวลาที่กำหนด ให้ประธานคณะอนุกรรมาธิการขออนุญาตขยายเวลาต่อที่ประชุมคณะกรรมาธิการ

ประธานคณะอนุกรรมาธิการต้องเป็นกรรมาธิการ

<!-- page 16 -->
<a id="clause-68"></a>**ข้อ 68** เมื่อคณะกรรมาธิการสามัญได้กระทำกิจการ พิจารณาสอบสวน หรือศึกษาเรื่องใด ๆ ตามอำนาจหน้าที่หรือตามที่สภามอบหมาย ให้คณะกรรมาธิการสามัญรายงานให้ประธานสภาทราบ

ในการกระทำกิจการ พิจารณาสอบสวน หรือศึกษาเรื่องใด ๆ ต้องไม่เป็นเรื่องซ้ำซ้อนกับคณะกรรมาธิการอื่น ในกรณีที่การกระทำนั้นเกี่ยวข้องกัน ให้เป็นหน้าที่ของประธานสภาที่จะต้องดำเนินการให้คณะกรรมาธิการสามัญที่เกี่ยวข้องกันทุกคณะร่วมกันดำเนินการ

<a id="clause-69"></a>**ข้อ 69** เมื่อคณะกรรมาธิการได้กระทำกิจการ พิจารณาสอบสวน หรือศึกษาเรื่องใด ๆ เสร็จสิ้นแล้วให้รายงานต่อสภา โดยแจ้งให้ประธานสภาทราบ เพื่อบรรจุเข้าระเบียบวาระการประชุมตามข้อ 13 (4)

ในที่ประชุมสภา คณะกรรมาธิการมีสิทธิแถลง ชี้แจง หรือแก้ไขเพิ่มเติมเกี่ยวกับการกระทำดังกล่าวในวรรคหนึ่ง ในการนี้ คณะกรรมาธิการอาจมอบหมายให้บุคคลใดแถลงหรือชี้แจงแทนก็ได้ เมื่อได้รับอนุญาตจากประธาน

<a id="clause-70"></a>**ข้อ 70** ถ้าสภามีมติให้คณะกรรมาธิการใดกระทำกิจการ พิจารณาสอบสวน หรือศึกษาเรื่องใดให้เสร็จภายในกำหนดเวลาใด และคณะกรรมาธิการนั้นกระทำกิจการ พิจารณาสอบสวน หรือศึกษาไม่เสร็จภายในเวลาที่กำหนด ประธานคณะกรรมาธิการต้องรายงานให้ประธานสภาทราบโดยด่วน หรือขอให้สภามีมติขยายเวลา

<a id="clause-71"></a>**ข้อ 71** กรรมาธิการพ้นจากตำแหน่ง เมื่อ

1. (1) สภาสิ้นอายุหรือสภาถูกยุบ
2. (2) ตาย
3. (3) ลาออก
4. (4) มีการตั้งคณะกรรมาธิการใหม่แทนคณะเดิม
5. (5) ขาดการประชุมสามครั้งติดต่อกันโดยไม่มีเหตุผลอันสมควร และไม่ได้แจ้งเป็นหนังสือให้ประธานคณะกรรมาธิการทราบ
6. (6) สภามีมติให้พ้นจากตำแหน่ง ตามญัตติในข้อ 31 ด้วยคะแนนเสียงเห็นชอบเกินกึ่งหนึ่งของจำนวนสมาชิกเท่าที่มีอยู่ของสภา

<!-- page 17 -->
<a id="clause-72"></a>**ข้อ 72** อนุกรรมาธิการพ้นจากตำแหน่ง เมื่อ

1. (1) สภาสิ้นอายุ
2. (2) ตาย
3. (3) ลาออก
4. (4) มีการยุบคณะกรรมาธิการที่สังกัด
5. (5) คณะกรรมาธิการที่สังกัดมีมติให้พ้นจากตำแหน่ง

เมื่ออนุกรรมาธิการพ้นจากตำแหน่งโดยวิธีใด ๆ ที่ไม่ใช่ (1) ให้มีการรายงานเป็นหนังสือต่อประธานสภา และให้มีประกาศสภา เรื่อง การสิ้นสภาพของอนุกรรมาธิการ ภายในสิบห้าวันนับตั้งแต่ได้รับรายงาน

<a id="clause-73"></a>**ข้อ 73** ในกรณีที่ตำแหน่งกรรมาธิการในคณะกรรมาธิการใดว่างลง ให้เป็นอำนาจของประธานคณะกรรมาธิการในการแต่งตั้งสมาชิกเป็นกรรมาธิการแทนโดยต้องแจ้งให้ประธานสภาทราบถึงการแต่งตั้งนั้นภายในเจ็ดวันนับแต่แต่งตั้ง

<a id="clause-74"></a>**ข้อ 74** ผู้เข้าร่วมการประชุมคณะกรรมาธิการ นอกจากกรรมาธิการและอนุกรรมาธิการ ให้ถือเป็นผู้สังเกตการณ์

ผู้สังเกตการณ์มีสิทธิเข้าประชุมคณะกรรมาธิการ แต่ไม่มีสิทธิลงคะแนนเสียงและปฏิบัติหน้าที่ในเรื่องต่าง ๆ ของคณะกรรมาธิการ

ผู้สังเกตการณ์ไม่สามารถออกความเห็นเข้าไปในบริเวณที่ประชุมหรือสำนักงานของคณะกรรมาธิการและให้หมายรวมถึงช่องทางผ่านสื่ออิเล็กทรอนิกส์ ทั้งนี้ เว้นแต่ได้รับคำอนุญาตจากประธานคณะกรรมาธิการให้เป็นอื่นแล้วแต่กรณี

หากประธานคณะกรรมาธิการเห็นสมควร จะไม่ให้ผู้สังเกตการณ์เข้าประชุมก็ได้ โดยอาจแจ้งเหตุผลในภายหลัง และให้คำวินิจฉัยของประธานคณะกรรมาธิการถือเป็นเด็ดขาด

<a id="clause-75"></a>**ข้อ 75** คณะกรรมาธิการเต็มสภา คือ คณะกรรมาธิการที่ประกอบด้วยสมาชิกทั้งหมดในที่ประชุมสภาเป็นกรรมาธิการ โดยประธานของที่ประชุมสภาทำหน้าที่เป็นประธานคณะกรรมาธิการ

<!-- page 18 -->
<a id="clause-76"></a>**ข้อ 76** คณะกรรมาธิการเต็มสภาจะเกิดขึ้นก็ต่อเมื่อสภาได้รับหลักการของญัตติใด ๆ แล้วแต่เนื่องจากมีความจำเป็นเร่งด่วนเพื่อประโยชน์ของนักศึกษา มหาวิทยาลัย และสภา โดยมีสมาชิกร้องขอและต้องมีสมาชิกรับรองไม่น้อยกว่าสองในสามขององค์ประชุม

ในการนี้ ให้เลขาธิการบันทึกถึงเหตุจำเป็นเร่งด่วนตามวรรคหนึ่ง

การประชุมคณะกรรมาธิการเต็มสภาให้ถือเป็นการประชุมสภาโดยอนุโลม

## หมวด 4 กระทู้ถาม

### ส่วนที่ 1 บททั่วไป

<a id="clause-77"></a>**ข้อ 77** กระทู้ถาม คือ ข้อซักถามที่สมาชิกมีต่อนายกองค์การนักศึกษา อุปนายกองค์การนักศึกษา คณะกรรมการบริหารสภา หรือสมาชิก หรือบุคคลภายนอก แล้วแต่กรณี เกี่ยวกับงานในหน้าที่ โดยจะถามเป็นหนังสือหรือด้วยวาจาก็ได้

<a id="clause-78"></a>**ข้อ 78** กระทู้ถามมี 2 ประเภท คือ

1. (1) กระทู้ถามสดด้วยวาจา
2. (2) กระทู้ถามทั่วไป

<a id="clause-79"></a>**ข้อ 79** การตั้งกระทู้ถาม ให้ผู้ตั้งกระทู้ถามมีอิสระ ไม่อยู่ในความผูกมัดแห่ง อาณัติมอบหมาย หรือความครอบงำใด ๆ กระทู้ถามแต่ละกระทู้นั้น ให้ตั้งถาม และซักถามได้เฉพาะคนเดียว

<a id="clause-80"></a>**ข้อ 80** กระทู้ถามต้องไม่มีลักษณะอย่างหนึ่งอย่างใด ดังต่อไปนี้

<!-- page 19 -->
1. (1) เป็นเชิงประชด เสียดสี หรือกลั่นแกล้งใส่ร้าย
2. (2) เคลือบคลุมหรือเข้าใจยาก
3. (3) เป็นเรื่องที่ได้ตอบแล้วหรือชี้แจงแล้วว่าไม่ตอบ
4. (4) เป็นเรื่องที่มีประเด็นคำถามซ้ำกับกระทู้ถามซึ่งมีผู้เสนอมาก่อน
5. (5) เป็นการให้ออกความเห็น
6. (6) เป็นปัญหาข้อกฎหมาย
7. (7) เป็นเรื่องที่ไม่มีสาระสำคัญ
8. (8) เป็นเรื่องส่วนตัวของบุคคลใด เว้นแต่ที่เกี่ยวกับการงานในหน้าที่

<a id="clause-81"></a>**ข้อ 81** กระทู้ถามตามข้อ 80 (3) และ (4) นั้น จะตั้งกระทู้ถามขึ้นใหม่ได้ ในเมื่อสาระสำคัญต่างกัน หรือพฤติการณ์ในขณะที่มีกระทู้ถามครั้งนั้นได้เปลี่ยนแปลง ไปจากเมื่อตั้งกระทู้ถามครั้งก่อน

<a id="clause-82"></a>**ข้อ 82** กระทู้ถามที่สมาชิกตั้งถามให้ประธานสภาทำการตรวจสอบ และหากมีข้อบกพร่องให้ประธานสภาแจ้งสมาชิกผู้นั้นทราบ

<a id="clause-83"></a>**ข้อ 83** การประชุมครั้งหนึ่ง ๆ ให้บรรจุกระทู้ถามสดด้วยวาจาได้ไม่เกินสามกระทู้และกระทู้ถามทั่วไปไม่เกินสามกระทู้ แต่ถ้าหากมีกระทู้ถามทั่วไปรอบรรจุระเบียบวาระการประชุมจำนวนมากหรือมีกระทู้ถามทั่วไปที่เลื่อนมาจากการประชุมครั้งที่แล้ว ประธานสภาจะบรรจุกระทู้ถามทั่วไปเกินกว่านี้ก็ได้

การจัดลำดับกระทู้ถามในที่ประชุม ให้จัดตามลำดับ คือ กระทู้ถามสดด้วยวาจา และกระทู้ถามทั่วไป

<a id="clause-85"></a>**ข้อ 85** นายกองค์การนักศึกษา อุปนายกองค์การนักศึกษา คณะกรรมการบริหารสภา หรือสมาชิก หรือบุคคลภายนอก แล้วแต่กรณี ที่ถูกตั้งกระทู้ถามต้องเข้าร่วมประชุมสภา เพื่อตอบกระทู้ถามในเรื่องนั้นด้วยตนเอง เว้นแต่มีเหตุจำเป็นอันมิอาจหลีกเลี่ยงได้ ทำให้ไม่อาจตอบกระทู้ แต่ต้องแจ้งเหตุจำเป็นนั้นเป็นหนังสือต่อประธานสภาก่อนหรือในวัน ประชุมสภา และให้กำหนดว่าจะตอบได้เมื่อใด ในกรณีที่มีการมอบหมายให้ผู้อื่นที่เกี่ยวข้องเป็นผู้ตอบกระทู้ถาม จะต้อง แจ้งเป็นหนังสือต่อประธานสภาก่อนถึงระเบียบวาระกระทู้ถาม นายกองค์การนักศึกษา อุปนายกองค์การนักศึกษา คณะกรรมการบริหารสภา หรือสมาชิก หรือบุคคลภายนอกย่อมมี

<!-- page 20 -->
สิทธิที่จะไม่ตอบกระทู้ถามเมื่อผู้ตั้งกระทู้ เห็นว่าเรื่องนั้นยังไม่ควรเปิดเผย เพราะเกี่ยวกับความปลอดภัยหรือประโยชน์สำคัญของมหาวิทยาลัย

<a id="clause-86"></a>**ข้อ 86** การตั้งกระทู้ถามต้องชัดเจน ไม่ฟุ่มเฟือย วนเวียน ซ้ำซาก หรือ มีลักษณะเป็นการอภิปราย

<a id="clause-87"></a>**ข้อ 87** ผู้ตั้งกระทู้ถามมีสิทธิถอนกระทู้ถามเมื่อใดก็ได้

<a id="clause-88"></a>**ข้อ 88** กระทู้ถามใดที่ประธานสภาพิจารณาเห็นว่าเหตุการณ์ได้เปลี่ยนแปลงไป ประธานสภาอาจสั่งให้นำออกจากการรอบรรจุระเบียบวาระการประชุมได้ เมื่อได้รับ ความยินยอมของผู้ตั้งกระทู้ถาม

<a id="clause-89"></a>**ข้อ 89** กระทู้ถามตกไป เมื่อ

1. (1) ถึงระเบียบวาระกระทู้ถามของผู้ใด ถ้าผู้ตั้งกระทู้ถามไม่ถามหรือไม่อยู่ในที่ประชุม
2. (2) สมาชิกภาพของผู้ตั้งกระทู้ถามสิ้นสุดลง
3. (3) ผู้ถูกตั้งกระทู้พ้นจากตำแหน่ง
4. (4) สภาสิ้นอายุ

### ส่วนที่ 2 กระทู้ถามสดด้วยวาจา

<a id="clause-90"></a>**ข้อ 90** การตั้งกระทู้ถามสดด้วยวาจา สมาชิกแต่ละคนมีสิทธิตั้งกระทู้ถาม ได้ครั้งละหนึ่งกระทู้ ในวันที่มีประชุม โดยไม่ต้องแจ้งล่วงหน้า และต้องมีลักษณะอย่างหนึ่งอย่างใด ดังต่อไปนี้

1. (1) เป็นเรื่องสำคัญที่อยู่ในความสนใจของนักศึกษา
2. (2) เป็นเรื่องที่กระทบถึงผลประโยชน์ของมหาวิทยาลัยและนักศึกษา
3. (3) เป็นเรื่องเร่งด่วน ให้เป็นอำนาจของประธานสภาที่จะวินิจฉัยว่ากระทู้ถามใดเป็นกระทู้ถามสด ด้วยวาจาหรือไม่

<!-- page 21 -->
<a id="clause-91"></a>**ข้อ 91** ในการประชุมครั้งใดมีกระทู้ถามสดด้วยวาจาที่ประธานสภาวินิจฉัย แล้วเกินจำนวนสามกระทู้ ให้ประธานสภาจับสลากให้เหลือเพียงสามกระทู้ ในจำนวน สามกระทู้นี้ หากปรากฏว่ามีกระทู้ถามที่เป็นเรื่องทำนองเดียวกัน ให้กระทู้ถามที่ถูกจับสลาก ขึ้นมาในลำดับหลังตกไป

<a id="clause-92"></a>**ข้อ 92** กระทู้ถามสดด้วยวาจาที่ประธานสภาวินิจฉัยตามข้อ 90 หรือได้ ดำเนินการตามข้อ 91 แล้ว ให้บรรจุเข้าระเบียบวาระกระทู้ถามสดด้วยวาจา

<a id="clause-93"></a>**ข้อ 93** การถามและการตอบกระทู้ถามสดด้วยวาจาในการประชุมครั้งหนึ่ง ๆ มีกำหนดเวลาไม่เกินเก้าสิบนาที เรื่องใดที่ประธานสภาวินิจฉัยว่าไม่เข้าลักษณะกระทู้ถามสดด้วยวาจาตามข้อ 90 หรือไม่อนุญาตให้บรรจุเข้าระเบียบวาระการประชุม หรือมิได้มีการถามตอบด้วยเหตุอื่นใด ที่มิใช่การขอเลื่อนการตอบของผู้ถูกตั้งกระทู้ให้เป็นอันตกไป หากสมาชิกยัง ประสงค์ที่จะตั้งเป็นกระทู้ถามสดด้วยวาจาอยู่ ให้เสนอใหม่เพื่อพิจารณาในคราวถัดไป

<a id="clause-94"></a>**ข้อ 94** กระทู้ถามสดด้วยวาจาแต่ละกระทู้ให้ถามได้เรื่องละไม่เกินสามครั้ง และต้องถามตอบให้แล้วเสร็จภายในกำหนดเวลาสามสิบนาที เว้นแต่ในการประชุมครั้งใด มีกระทู้ถามสดด้วยวาจาน้อยกว่าสามกระทู้ ก็ให้ขยายเวลาออกไปอีกตามสัดส่วนภายใน เวลาหกสิบนาที

<a id="clause-95"></a>**ข้อ 95** ในระหว่างการถามกระทู้ถามสดด้วยวาจา หากประธานวินิจฉัยว่า คำถามข้อใดเข้าลักษณะต้องห้ามตามข้อ 80 ให้ประธานมีอำนาจสั่งให้เปลี่ยนแปลง คำถาม

### ส่วนที่ 3 กระทู้ถามทั่วไป

<a id="clause-96"></a>**ข้อ 96** การตั้งกระทู้ถามทั่วไปให้เสนอล่วงหน้าเป็นหนังสือยื่นต่อประธานสภา โดยมีข้อความเป็นคำถามในข้อเท็จจริงหรือนโยบาย และระบุว่าจะให้ตอบในที่ประชุมสภา

<a id="clause-97"></a>**ข้อ 97** ให้ประธานสภาวินิจฉัยว่ากระทู้ถามใดมีลักษณะต้องห้ามตามข้อ 80 หรือมีลักษณะตามข้อ 81 และเมื่อวินิจฉัยแล้วให้แจ้งผู้ตั้งกระทู้ถามทราบภายในเจ็ดวัน กระทู้ถามที่ประธานสภาวินิจฉัยว่าเป็นกระทู้ถาม ให้จัดส่งไปยังผู้ที่ที่ถูกตั้งกระทู้ถาม

<!-- page 22 -->
<a id="clause-98"></a>**ข้อ 98** กระทู้ถามที่ต้องตอบในที่ประชุมสภา ให้บรรจุเข้าระเบียบวาระ การประชุมภายในสิบห้าวันนับแต่วันที่ส่งไปยังนายกรัฐมนตรีหรือรัฐมนตรีตามข้อ 97 วรรคสอง

<a id="clause-99"></a>**ข้อ 99** การตั้งกระทู้ถามทั่วไปตามข้อ 96 ในการประชุมให้บรรจุกระทู้ ลำดับแรกของสมาชิกเข้าระเบียบวาระการประชุมตามลำดับก่อนหลังที่ได้ยื่นต่อประธานสภา

## หมวด 5 การเปิดอภิปรายทั่วไป

### ส่วนที่ 1 การเปิดอภิปรายทั่วไปเพื่อลงมติไม่ไว้วางใจ

<a id="clause-100"></a>**ข้อ 100** เมื่อสมาชิกมีความประสงค์จะเสนอญัตติขอให้เปิดอภิปรายทั่วไปให้ยื่นต่อประธานสภาเป็นหนังสือแสดงว่า จะเปิดอภิปรายทั่วไปเพื่อลงมติไม่ไว้วางใจคณะกรรมการบริหารเป็นรายบุคคลหรือทั้งคณะในเรื่องใดบ้าง

<a id="clause-101"></a>**ข้อ 101** เมื่อประธานสภาได้รับญัตติตามข้อ 100 แล้ว ให้ทำการตรวจสอบ หากมีข้อบกพร่องให้ประธานสภาแจ้งผู้เสนอทราบภายในเจ็ดวันนับแต่วันที่ได้รับญัตติ เมื่อประธานสภาได้ตรวจสอบความถูกต้องของญัตติแล้ว ให้บรรจุเข้าระเบียบวาระการประชุมเป็นเรื่องด่วนและคณะกรรมการบริหารสภาทราบ

<a id="clause-102"></a>**ข้อ 102** คณะกรรมการบริหารสภาเท่านั้นที่มีสิทธิอภิปรายชี้แจง

การชี้แจงตามวรรคหนึ่ง จะชี้แจงคำอภิปรายของสมาชิกทีละคนเป็นลำดับไป หรือจะรอรวมชี้แจงครั้งละหลายคนก็ได้

<a id="clause-103"></a>**ข้อ 103** ในการอภิปราย ให้นำความในหมวด 2 ส่วนที่ 3 การอภิปราย มาใช้ บังคับโดยอนุโลม

<!-- page 23 -->
### ส่วนที่ 2 การเปิดอภิปรายทั่วไปโดยไม่มีการลงมติ

<a id="clause-104"></a>**ข้อ 104** ญัตติขอเปิดอภิปรายทั่วไปโดยไม่มีการลงมติ ให้ทำเป็นหนังสือยื่นต่อประธานสภาโดยระบุให้ชัดเจนว่าจะซักถามข้อเท็จจริงหรือเสนอแนะ ปัญหาต่อบุคคลใดในเรื่องใด

เมื่อประธานสภาได้รับญัตติตามวรรคหนึ่งแล้ว ให้นำความในข้อ 101 มาใช้บังคับ โดยอนุโลม

<a id="clause-105"></a>**ข้อ 105** ในการอภิปราย ให้นำความในหมวด 2 ส่วนที่ 3 การอภิปราย มาใช้ บังคับโดยอนุโลม

## หมวด 6 การจัดระเบียบและความเรียบร้อย

<a id="clause-106"></a>**ข้อ 106** ห้ามกระทำการใด ๆ อันเป็นการรบกวนต่อการประชุมสภา

<a id="clause-107"></a>**ข้อ 107** ผู้ใดฝ่าฝืนระเบียบนี้ ประธานมีอำนาจเตือน ห้ามปราม ให้ถอนคำพูด ห้ามพูดในเรื่องที่กำลังปรึกษากันอยู่ ให้กล่าวขออภัยในที่ประชุม หรือสั่งให้ออกไปจากที่ประชุมโดยมีหรือไม่มีกำหนดเวลาในครั้งนั้นก็ได้

ในกรณีที่ประธานสั่งให้ผู้ใดออกจากที่ประชุม หากผู้นั้นขัดขืน ประธานมีอำนาจสั่งให้เจ้าหน้าที่รักษาความปลอดภัยหรือพนักงานของมหาวิทยาลัย นำตัวออกจากสถานที่ประชุมหรือออกไปพ้นบริเวณสภา

ในการประชุมผ่านสื่ออิเล็กทรอนิกส์ หากผู้นั้นขัดขืน ประธานมีอำนาจขับออกจากที่ประชุมตามวิธีการที่ประธานกำหนด

คำสั่งของประธานตามข้อนี้ ถือเป็นที่สุด

<a id="clause-108"></a>**ข้อ 108** การขานชื่อและการระบุชื่อของบุคคล ให้กระทำดังนี้

1. (1) ในการขานชื่อ หรือระบุชื่อตนเอง ให้เป็นเสรีภาพของบุคคลนั้นที่จะใช้หรือไม่ใช้คำนำหน้านามก็ได้

<!-- page 24 -->
1. (2) ในการขานชื่อ หรือระบุชื่อของบุคคลอื่น ต้องไม่ขานหรือระบุคำนำหน้านามของบุคคลนั้น เว้นแต่บุคคลนั้นประสงค์ให้ใช้คำนำหน้านาม

<a id="clause-109"></a>**ข้อ 109** การแต่งกายเข้าที่ประชุมสภาหรือบริเวณสภา เป็นเสรีภาพของบุคคลที่จะแต่งกายแบบใดก็ได้ แต่ต้องไม่เปลือยเปล่า

การแสดงสื่อหรือภาพที่มีถ้อยคำผรุสวาทหรือคำหยาบคายในการประชุมผ่านสื่ออิเล็กทรอนิกส์สามารถทำได้ โดยต้องไม่เป็นการโจมตีบุคคลใดบุคคลหนึ่งโดยเฉพาะเจาะจง และต้องไม่แสดงภาพลามกอนาจาร

<a id="clause-110"></a>**ข้อ 110** สมาชิกมีสิทธิในการเข้าประชุมสภาและประชุมคณะกรรมาธิการ โดยไม่สามารถมีบุคคลใดมาขัดขวางได้ เว้นแต่การฝ่าฝืนระเบียบนี้ตามข้อ 78

## หมวด 7 การสิ้นสภาพของคณะกรรมการบริหารสภา

<a id="clause-111"></a>**ข้อ 111** คณะกรรมการบริหารสภาพ้นจากตำแหน่ง เมื่อ

1. (1) สภาสิ้นอายุ
2. (2) ตาย
3. (3) ลาออก
4. (4) พ้นจากตำแหน่งสมาชิก
5. (5) สภามีมติให้พ้นจากตำแหน่ง ตามญัตติในข้อ 30 ด้วยคะแนนเสียงเห็นชอบไม่น้อยกว่าสองในสามของจำนวนสมาชิกเท่าที่มีอยู่ของสภา

<!-- page 25 -->
## หมวด 8 คำสั่งสภา

<a id="clause-112"></a>**ข้อ 112** คำสั่งสภา คือ คำสั่งซึ่งคณะกรรมการบริหารสภา มีมติเห็นชอบให้ออกคำสั่งต่อกรรมการบริหารสภา หรืออาจรวมไปถึงสมาชิก แล้วแต่กรณี ให้ทำหน้าที่ หยุดปฏิบัติหน้าที่ หรือกระทำกิจการใด ๆ ที่ซึ่งเกี่ยวข้องกับผลประโยชน์ของนักศึกษา มหาวิทยาลัย และสภา

ทั้งนี้คำสั่งให้กรรมการบริหารสภา ยุติการปฏิบัติหน้าที่ชั่วคราวต้องมีมติเห็นชอบจากคณะกรรมการประสานงานร่วมด้วย

ให้ประธานสภาแถลงถึงความจำเป็นในการออกคำสั่งสภาต่อสมาชิกภายในหนึ่งวันนับตั้งแต่ประธานสภาลงนามในเอกสารคำสั่งสภา

คำสั่งสภาถือเป็นมติของสภา

<a id="clause-113"></a>**ข้อ 113** ต้องเผยแพร่คำสั่งสภาต่อสาธารณะผ่านสื่ออิเล็กทรอนิกส์ของสภาภายในสามวันนับตั้งแต่ประธานลงนามในคำสั่งสภา เว้นแต่สมาชิกจะร้องขอให้เป็นการลับ โดยมีมติเห็นชอบไม่น้อยกว่าหนึ่งในสามของสมาชิกทั้งหมดเท่าที่มีอยู่

หากมีสมาชิกคัดค้าน และร้องขอให้เผยแพร่ต่อสาธารณะ ต้องมีมติของสมาชิกเห็นชอบเกินหนึ่งในสี่ของสมาชิกทั้งหมดเท่าที่มีอยู่ จึงจะเผยแพร่ได้

<!-- page 26 -->
## หมวด 9 บทสุดท้าย

<a id="clause-114"></a>**ข้อ 114** ถ้าประธานขอปรึกษาหรือมีสมาชิกเสนอญัตติโดยมีสมาชิกรับรองไม่น้อยกว่าสิบคนให้งดใช้ระเบียบนี้ข้อหนึ่งข้อใดทั้งหมดหรือบางส่วนเป็นการชั่วคราวเฉพาะกรณี หากที่ประชุมอนุมัติด้วยคะแนนเสียงไม่น้อยกว่าสองในสามขององค์ประชุม ก็ให้งดใช้ได้

<a id="clause-115"></a>**ข้อ 115** ถ้าประธานสภาวินิจฉัยแล้วว่าการดำเนินงานใดเป็นเรื่องเร่งด่วนอย่างยิ่ง ให้คณะกรรมการบริหารสภาและคณะกรรมการประสานงานร่วมสภา มีมติเห็นชอบไม่น้อยกว่าสองในสามของจำนวนกรรมการเท่าที่มีอยู่ของแต่ละคณะ โดยต้องแจ้งสมาชิกให้ทราบถึงเหตุผลและการดำเนินการดังกล่าว จึงจะถือว่าเป็นมติสภาโดยอนุโลม

<a id="clause-116"></a>**ข้อ 116** ถ้ามีปัญหาที่จะต้องตีความตามระเบียบนี้ ให้เป็นอำนาจของสภาที่จะวินิจฉัย และเมื่อที่ประชุมได้ลงมติวินิจฉัยโดยคะแนนเสียงไม่น้อยกว่ากึ่งหนึ่งของจำนวนสมาชิกเท่าที่มีอยู่ของสภาเป็นประการใดแล้ว ให้ถือว่าคำวินิจฉัยนั้นเป็นเด็ดขาด

การขอให้ที่ประชุมวินิจฉัยตามวรรคหนึ่ง อาจกระทำได้โดยประธานขอปรึกษาหรือสมาชิกเสนอญัตติโดยมีสมาชิกรับรองไม่น้อยกว่าสิบคน

<a id="clause-117"></a>**ข้อ 117** การขอแก้ไขเพิ่มเติมระเบียบนี้ ต้องเสนอเป็นญัตติโดยมีสมาชิกรับรองไม่น้อยกว่าสิบคน การลงมติแก้ไขเพิ่มเติมระเบียบนี้ ต้องได้รับการอนุมัติด้วยคะแนนเสียงไม่น้อยกว่าสองในสามของจำนวนสมาชิกทั้งหมดเท่าที่มีอยู่ของสภา

<a id="clause-118"></a>**ข้อ 118** การคัดค้านคำวินิจฉัยหรือดุลพินิจของประธาน สามารถกระทำได้ในกรณีที่สมาชิกเสนอญัตติให้มีมติคัดค้านโดยมีสมาชิกรับรองไม่น้อยกว่าสิบคน และมีคะแนนเกินกึ่งหนึ่งขององค์ประชุม เว้นแต่คำวินิจฉัยซึ่งถือเป็นที่สุดตามระเบียบ

# ระเบียบกิจกรรมนักศึกษามหาวิทยาลัยธรรมศาสตร์
## ว่าด้วยการดำเนินงานและการประชุมสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ พ.ศ. ๒๕๖๔

อาศัยอำนาจตามความในข้อ ๒๙ แห่งข้อบังคับมหาวิทยาลัยธรรมศาสตร์ ว่าด้วยกิจกรรมนักศึกษา พ.ศ.๒๕๖๓ เพื่อให้การดำเนินงานและการประชุมของสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ เป็นไปด้วยความราบรื่นเรียบร้อย สภานักศึกษามหาวิทยาลัยธรรมศาสตร์ จึงตรากิจกรรมนักศึกษามหาวิทยาลัยธรรมศาสตร์ ว่าด้วยการดำเนินงานและการประชุมสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ พ.ศ. ๒๕๖๔ ดังนี้

<a id="clause-1"></a>**ข้อ ๑** ระเบียบนี้เรียกว่า “ระเบียบกิจกรรมนักศึกษา ว่าด้วยการดำเนินงานและการประชุมสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ พ.ศ.๒๕๖๔”

<a id="clause-2"></a>**ข้อ ๒** ระเบียบนี้ให้ใช้บังคับนับแต่วันที่ สภานักศึกษามหาวิทยาลัยธรรมศาสตร์ มีมติเห็นชอบเป็นต้นไป

<a id="clause-3"></a>**ข้อ ๓** ในระเบียบนี้

“ประธานสภา” หมายความว่า ประธานสภานักศึกษามหาวิทยาลัยธรรมศาสตร์

“รองประธานสภา” หมายความว่า รองประธานสภานักศึกษามหาวิทยาลัยธรรมศาสตร์

“สภา” หมายความว่า สภานักศึกษามหาวิทยาลัยธรรมศาสตร์

“ประธาน” หมายความว่า ประธานของที่ประชุมสภานักศึกษามหาวิทยาลัยธรรมศาสตร์

“สมาชิก” หมายความว่า สมาชิกสภานักศึกษามหาวิทยาลัยธรรมศาสตร์

“กรรมาธิการ” หมายความว่า กรรมาธิการสามัญหรือกรรมาธิการวิสามัญ สภานักศึกษามหาวิทยาลัยธรรมศาสตร์

“อนุกรรมาธิการ” หมายความว่า บุคคลซึ่งสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ แต่งตั้งขึ้นเพื่อช่วยเหลือกิจการใด ๆ ของสภานักศึกษามหาวิทยาลัยธรรมศาสตร์

<!-- page 2 -->

“เลขาธิการ” หมายความว่า เลขาธิการสภานักศึกษามหาวิทยาลัยธรรมศาสตร์

“รองเลขาธิการ” หมายความว่า รองเลขาธิการสภานักศึกษามหาวิทยาลัยธรรมศาสตร์

“การประชุม” หมายความว่า การประชุมสภานักศึกษามหาวิทยาลัยธรรมศาสตร์

“ที่ประชุม” หมายความว่า ที่ประชุมสภานักศึกษามหาวิทยาลัยธรรมศาสตร์

“บริเวณสภา” หมายความว่า อาณาบริเวณอันเป็นขอบเขตรับผิดชอบของสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ สถานที่สำหรับใช้ในการประชุมทั้งเป็นการถาวรหรือเป็นการชั่วคราว สำนักงานคณะกรรมการบริหารสภานักศึกษา และให้หมายความรวมถึง บัญชีผู้ใช้ ห้องสนทนา ห้องประชุม และอื่น ๆ ของสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ ซึ่งอาศัยผ่านทางสื่ออิเล็กทรอนิกส์ด้วย

“พรรค” หมายความว่า พรรคนักศึกษา มหาวิทยาลัยธรรมศาสตร์

“มหาวิทยาลัย” หมายความว่า มหาวิทยาลัยธรรมศาสตร์

<a id="clause-4"></a>**ข้อ ๔** ให้ประธานสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ รักษาการตามระเบียบนี้ และมีอำนาจออกระเบียบเพื่อปฏิบัติการตามระเบียบนี้

## หมวด ๑ คณะกรรมการประสานงานร่วมสภา

<a id="clause-5"></a>**ข้อ ๕** ให้มีคณะกรรมการคณะหนึ่งเรียกว่า “คณะกรรมการประสานงานร่วมสภา” ประกอบด้วยประธานสภาหรือรองประธานสภาที่ประธานสภามอบหมายเป็นประธานคณะกรรมการและกรรมการอื่นอีกไม่เกินเก้าคน ซึ่งประธานสภาแต่งตั้งจากสมาชิกซึ่งเป็นกรรมการประสานงานพรรคนักศึกษาอย่างน้อยจำนวนหนึ่งคนต่อหนึ่งพรรค ตามมติของแต่ละพรรค

<a id="clause-6"></a>**ข้อ ๖** กรรมการประสานงานร่วมสภา พ้นจากตำแหน่ง เมื่อ

- (๑) สภาสิ้นอายุ หรือสภาถูกยุบ
- (๒) ตาย
- (๓) ลาออก

<!-- page 3 -->

- (๔) พ้นจากการเป็นสมาชิก
- (๕) มีการแต่งตั้งคณะกรรมการประสานงานร่วมสภาใหม่แทนคณะเดิม

<a id="clause-7"></a>**ข้อ ๗** คณะกรรมการประสานงานร่วมสภามีอำนาจและหน้าที่ ดังต่อไปนี้

- (๑) พิจารณาดำเนินการหรือประสานงานในเรื่องที่เกี่ยวข้องกับการประชุมและกิจการสภา
- (๒) หน้าที่และอำนาจอื่นตามที่ประธานสภามอบหมาย

## หมวด ๒ การประชุม

### ส่วนที่ ๑ วิธีการประชุม

<a id="clause-8"></a>**ข้อ ๘** การประชุมย่อมเป็นการเปิดเผย เว้นแต่สมาชิกจำนวนไม่น้อยกว่าหนึ่งในสี่ของจำนวนสมาชิกทั้งหมดเท่าที่มีอยู่ของสภาร้องขอให้ประชุมลับ ก็ให้ประชุมลับ

การประชุมลับ ห้ามบุคคลภายนอกเข้ารับฟังการประชุม เว้นแต่ผู้ที่ได้รับอนุญาตจากประธานเท่านั้น

<a id="clause-9"></a>**ข้อ ๙** กรณีมีเหตุอันจำเป็นให้เรียกประชุม นอกเหนือจากการประชุมสมัยสามัญ ประธานสภาอาจให้เรียกประชุมสมัยวิสามัญได้

<a id="clause-10"></a>**ข้อ ๑๐** การนัดหมายประชุมต้องทำเป็นหนังสือแจ้งวัน เวลา สถานที่ และระเบียบวาระการประชุมให้สมาชิกทราบล่วงหน้าไม่น้อยกว่าเจ็ดวันสำหรับการประชุมสมัยสามัญ และไม่น้อยกว่าสามวันสำหรับการประชุมสมัยวิสามัญ

หากมีเหตุจำเป็นเร่งด่วนอันหลีกเลี่ยงมิได้ ให้ประธานสภาวินิจฉัยเพื่อการนัดหมายประชุมล่วงหน้าอย่างน้อยครึ่งชั่วโมง

<a id="clause-11"></a>**ข้อ ๑๑** ให้เลขาธิการส่งระเบียบวาระการประชุมและเอกสารที่เกี่ยวข้องไปพร้อมกับหนังสือนัดหมายประชุม หากประธานสภาเห็นสมควร จะบรรจุเรื่องใดเพิ่มเติมในระเบียบวาระการประชุมอีกก็ได้ แต่ต้องก่อนวันประชุมไม่น้อยกว่าหนึ่งวัน

<!-- page 4 -->

<a id="clause-12"></a>**ข้อ ๑๒** การนัดหมายประชุมตามข้อ ๑๐ และการส่งเอกสารตามข้อ ๑๑ อาจดำเนินการผ่านสื่ออิเล็กทรอนิกส์หรือสื่อเทคโนโลยีสารสนเทศประเภทอื่นเพิ่มเติมด้วยก็ได้ เมื่อประธานสภาเห็นสมควร เว้นแต่การจัดส่งเอกสารลับ ให้เป็นไปตามที่ประธานสภากำหนด

<a id="clause-13"></a>**ข้อ ๑๓** การจัดระเบียบวาระการประชุมให้จัดลำดับ ดังต่อไปนี้

- (๑) กระทู้ถาม
- (๒) เรื่องที่ประธานแจ้งให้ทราบ
- (๓) รับรองรายงานการประชุม
- (๔) เรื่องที่คณะกรรมาธิการพิจารณาเสร็จแล้ว
- (๕) เรื่องที่สืบเนื่องจากครั้งก่อน
- (๖) เรื่องที่เสนอให้ที่ประชุมพิจารณา
- (๗) เรื่องอื่น ๆ
- (๘) กำหนดการประชุมสภาครั้งต่อไป

ในกรณีที่ประธานสภาเห็นว่าเรื่องใดเป็นเรื่องด่วน จะจัดไว้ในลำดับใดของระเบียบวาระการประชุมก็ได้ แต่จะจัดไว้ก่อนเรื่องที่คณะกรรมาธิการพิจารณาเสร็จแล้วไม่ได้ เว้นแต่จะเป็นการเรียกนายกองค์การนักศึกษา อุปนายกองค์การนักศึกษา หรือผู้ได้รับมอบหมายให้ปฏิบัติหน้าที่แทน ให้เข้ามาชี้แจงหรือรายงานผลการดำเนินงาน ประธานสภาอาจจัดไว้ใน (๑) ได้

การตั้งกระทู้ถามกรรมการบริหารสภาหรือคณะกรรมการบริหารสภา สามารถกระทำได้ และให้ไว้ใน (๑) โดยจะต้องเสนอกระทู้นั้นต่อประธานก่อนวันประชุมอย่างน้อยหนึ่งวัน ซึ่งมีได้ไม่เกินสามกระทู้ กระทู้ละไม่เกินสิบห้านาที โดยผู้ถูกตั้งกระทู้ถามอาจตอบหรือไม่ก็ได้

กรณีการตั้งกระทู้ถามสดด้วยวาจา ซึ่งเสนอในที่ประชุม จะต้องเป็นเรื่องที่เกี่ยวข้องกับผลประโยชน์ของมหาวิทยาลัยหรือนักศึกษา หรือเรื่องสำคัญเร่งด่วน และไม่เป็นคำถามในลักษณะที่เป็นการโจมตีตัวบุคคลหรือกลุ่มบุคคล

คำวินิจฉัยของประธานเกี่ยวกับการตั้งกระทู้ตามวรรคสามและวรรคสี่ ให้ถือเป็นเด็ดขาด

<a id="clause-14"></a>**ข้อ ๑๔** ก่อนเข้าสู่ระเบียบวาระการประชุม ประธานสภาอาจอนุญาตให้สมาชิกปรึกษาหารือปัญหาที่เกี่ยวกับความเดือดร้อนของนักศึกษาหรือปัญหาอื่นใดได้ ตามหลักเกณฑ์และวิธีการที่ประธานสภากำหนด
<!-- page 5 -->
และให้ประธานส่งเรื่องดังกล่าวให้หน่วยงานของมหาวิทยาลัยที่เกี่ยวข้องชี้แจงภายในเวลาการประชุมสมัยสามัญครั้งต่อไป และแจ้งให้สมาชิกทราบ

<a id="clause-15"></a>**ข้อ ๑๕** ก่อนเข้าประชุมทุกครั้งให้สมาชิกมาประชุมลงชื่อในเอกสาร แบบลงชื่อประเภทอื่น ๆ หรือแสดงตนตามระเบียบที่ประธานสภากำหนด

เมื่อสมาชิกลงชื่อมาประชุมไม่น้อยกว่ากึ่งหนึ่งของจำนวนสมาชิกทั้งหมดเท่าที่มีอยู่จึงจะเป็นองค์ประชุม

เมื่อสมาชิกมาลงชื่อครบองค์ประชุมและมีสัญญาณให้เข้าประชุมแล้ว หลังจากนั้นภายในห้านาทีให้ประธานดำเนินการประชุม

<a id="clause-16"></a>**ข้อ ๑๖** หากสมาชิกไม่กระทำตามข้อ ๑๕ วรรคหนึ่ง โดยไม่มีการแจ้งให้ประธานทราบล่วงหน้า จะถือให้สมาชิกขาดประชุม

หากสมาชิกเข้าประชุมหรือออกจากที่ประชุม ระหว่างที่การประชุมกำลังดำเนินอยู่ ให้แจ้งต่อประธานหรือเลขาธิการทันที ในทุกกรณี

เมื่อประธานมีสัญญาณเพื่อเริ่มการประชุม ให้ทุกคนในที่ประชุมอยู่ในความสงบเรียบร้อย

<a id="clause-17"></a>**ข้อ ๑๗** เมื่อพ้นกำหนดประชุมไปสามสิบนาทีแล้ว หากจำนวนสมาชิกยังไม่ครบองค์ประชุม ประธานจะสั่งให้เลื่อนการประชุมไปก็ได้

<a id="clause-18"></a>**ข้อ ๑๘** ในการประชุมนั้น ให้ที่ประชุมพิจารณาเฉพาะเรื่องที่มีอยู่ในระเบียบวาระการประชุม และต้องดำเนินการพิจารณาตามลำดับระเบียบวาระการประชุมที่จัดไว้ เว้นแต่ที่ประชุมจะลงมติเป็นอย่างอื่น

<a id="clause-19"></a>**ข้อ ๑๙** ผู้ใดประสงค์จะกล่าวถ้อยคำต่อที่ประชุม ให้ยกมือขึ้นพ้นศีรษะ เมื่อประธานอนุญาตแล้วจึงกล่าวได้ และต้องเป็นคำกล่าวต่อประธานเท่านั้น

ในการประชุมผ่านสื่ออิเล็กทรอนิกส์ ให้ประธานกำหนดหลักเกณฑ์และวิธีการแสดงความประสงค์จะกล่าวถ้อยคำต่อที่ประชุมของสมาชิกตามสมควร

<a id="clause-20"></a>**ข้อ ๒๐** ประธานอาจปรึกษาหารือที่ประชุมในปัญหาใด ๆ กำหนดวิธีการตรวจสอบองค์ประชุม สั่งพักการประชุม เลื่อนการประชุม หรือเลิกการประชุมได้ตามที่เห็นสมควร

หากประธานออกจากที่ประชุมโดยมิได้มีการสั่งการแต่อย่างใด และไม่มีผู้ใดปฏิบัติหน้าที่แทน ให้เลิกการประชุม

<a id="clause-21"></a>**ข้อ ๒๑** รายงานการประชุม ให้เลขาธิการเป็นผู้จัดทำและผู้ตรวจทาน
<!-- page 6 -->
เมื่อเลขาธิการตรวจแล้ว ก่อนที่จะเสนอให้สภารับรอง ให้ทำสำเนาวางไว้ ณ บริเวณสภา หรือส่งสำเนาผ่านทางสื่ออิเล็กทรอนิกส์หรือสื่อเทคโนโลยีสารสนเทศอื่น ๆ ไม่น้อยกว่าสามวัน หรือด้วยวิธีการอื่นตามแต่ประธานจะเห็นสมควร เพื่อให้สมาชิกตรวจดูได้

รายงานการประชุมทุกครั้งจะต้องมีรายชื่อสมาชิกที่มาประชุม ที่ลาการประชุม ที่ขาดประชุม บันทึกการออกเสียงลงคะแนน

สมาชิกมีสิทธิขอแก้ไขเพิ่มเติมรายงานการประชุมดังกล่าวให้ตรงตามที่เป็นจริง โดยยื่นคำขอแก้ไขเพิ่มเติมต่อเลขาธิการ ถ้าเลขาธิการไม่ดำเนินการแก้ไขเพิ่มเติมให้ตามที่ขอ สมาชิกผู้นั้นมีสิทธิที่จะยืนยันคำขอแก้ไขเพื่อขอให้สภาวินิจฉัย

<a id="clause-22"></a>**ข้อ ๒๒** รายงานการประชุมครั้งใด เมื่อได้วางสำเนาไว้หรือส่งให้เพื่อให้สมาชิกตรวจดูแล้ว ถ้ามีการแก้ไขเพิ่มเติมในภายหลังโดยคณะกรรมาธิการแก้ไขเพิ่มเติมเองหรือโดยสมาชิกขอแก้ไขเพิ่มเติมก็ตาม ในคราวที่สภาพิจารณารับรองรายงานประชุมนั้น คณะกรรมาธิการหรือเลขาธิการจะต้องแถลงต่อที่ประชุมถึงการแก้ไขเพิ่มเติมดังกล่าว

<a id="clause-23"></a>**ข้อ ๒๓** เมื่อสภาได้รับรองรายงานการประชุมครั้งใดแล้ว ให้ประธานสภาลงลายมือชื่อไว้เป็นหลักฐาน

รายงานการประชุมที่ได้รับรองแล้ว แต่ประธานยังมิได้ลงลายชื่อไว้เป็นหลักฐานหรือรายงานการประชุมที่ยังมิได้มีการรับรองเพราะเหตุที่อายุของสภาสิ้นสุดลง ให้เลขาธิการบันทึกเหตุนั้นไว้ และเป็นผู้รับรองความถูกต้องของรายงานการประชุมนั้น

<a id="clause-24"></a>**ข้อ ๒๔** สภาอาจมีมติไม่ให้จดรายงานการประชุมลับครั้งใดทั้งหมด หรือแต่เพียงบางส่วนก็ได้แต่ให้มีบันทึกเหตุการณ์ไว้

<a id="clause-25"></a>**ข้อ ๒๕** การเปิดเผยรายงานการประชุมลับ ให้ที่ประชุมพิจารณาและมีมติจะเปิดเผยหรือไม่

<a id="clause-26"></a>**ข้อ ๒๖** ให้เลขาธิการเป็นผู้พิมพ์และโฆษณารายงานการประชุม ทั้งนี้ นอกจากรายงานการประชุมลับที่สภามีมติไม่ให้เปิดเผย

### ส่วนที่ ๒ การเสนอญัตติ

<a id="clause-27"></a>**ข้อ ๒๗** ญัตติ คือ ข้อเสนอใด ๆ ที่มีความมุ่งหมายให้สภาลงมติหรือชี้ขาดว่าจะให้ปฏิบัติหรือดำเนินการอย่างไรต่อไป

<!-- page 7 -->

<a id="clause-28"></a>**ข้อ ๒๘** ญัตติทั้งหลายต้องเสนอล่วงหน้าเป็นหนังสือต่อประธานสภา และต้องมีจำนวนสมาชิกรับรองไม่น้อยกว่าห้าคน ทั้งนี้ เว้นแต่ระเบียบนี้ได้กำหนดไว้โดยเฉพาะเป็นอย่างอื่น

<a id="clause-29"></a>**ข้อ ๒๙** ญัตติขอให้สภาตั้งคณะกรรมาธิการหรือขอให้คณะกรรมาธิการคณะใดคณะหนึ่งกระทำกิจการพิจารณา สอบสวน หรือศึกษาเรื่องใด ๆ อันอยู่ในอำนาจหน้าที่ของสภา ถ้าสมาชิกเป็นผู้เสนอต้องมีจำนวนสมาชิกรับรองไม่น้อยกว่าหนึ่งในสี่ของจำนวนสมาชิกทั้งหมดเท่าที่มีอยู่ของสภา

<a id="clause-30"></a>**ข้อ ๓๐** ญัตติขอให้กรรมการบริหารสภาพ้นจากตำแหน่ง ต้องมีจำนวนสมาชิกรับรองไม่น้อยกว่าหนึ่งในสามของจำนวนสมาชิกทั้งหมดเท่าที่มีอยู่ของสภา

<a id="clause-31"></a>**ข้อ ๓๑** ญัตติขอให้กรรมาธิการพ้นจากตำแหน่ง ต้องมีคณะกรรมาธิการที่สังกัดเสนอ ประกอบการระบุเหตุผลอันเป็นที่ประจักษ์ ลงในหนังสือต่อประธานสภา

<a id="clause-32"></a>**ข้อ ๓๒** ในกรณีที่เกี่ยวกับประโยชน์สำคัญของมหาวิทยาลัยหรือนักศึกษา หรือมีความจำเป็นเร่งด่วนอันเกี่ยวข้องกับสิทธิสวัสดิการของนักศึกษา สมาชิกจะเสนอญัตติด่วนเพื่อให้สภาพิจารณาเป็นการด่วนก็ได้ ญัตติด่วนต้องไม่มีลักษณะทำนองเดียวกับกระทู้ และต้องมีวัตถุประสงค์เพื่อให้สภาดำเนินการอย่างใดอย่างหนึ่งด้วย

<a id="clause-33"></a>**ข้อ ๓๓** ให้เป็นอำนาจของประธานสภาที่จะวินิจฉัยว่าญัตติใดเป็นญัตติด่วนหรือไม่ และเมื่อวินิจฉัยแล้ว ให้แจ้งผู้เสนอญัตติทราบพร้อมด้วยเหตุภายในสามวันนับแต่วันที่ได้รับญัตตินั้น

ให้ประธานสภาบรรจุญัตติด่วนเข้าระเบียบวาระประชุมเป็นเรื่องด่วน

ญัตติที่ประธานสภาวินิจฉัยว่าไม่ได้เป็นญัตติด่วน ให้ประธานสภาดำเนินการต่อไปตามข้อ ๓๔

<a id="clause-34"></a>**ข้อ ๓๔** ภายใต้บังคับข้อ ๓๓ ให้ประธานสภาบรรจุญัตติเข้าระเบียบวาระการประชุมภายในเจ็ดวัน นับแต่วันที่ได้รับญัตตินั้นตามลำดับที่ยื่นก่อนหลัง กำหนดวันดังกล่าวให้หมายถึงวันในสมัยประชุม

<a id="clause-35"></a>**ข้อ ๓๕** ญัตติต่อไปนี้ไม่ต้องเสนอล่วงหน้าหรือเป็นหนังสือ

- (๑) ขอให้พิจารณาเป็นเรื่องด่วน
- (๒) ขอเปลี่ยนระเบียบวาระการประชุม
- (๓) ญัตติที่ประธานอนุญาตตามที่เห็นสมควร

<a id="clause-36"></a>**ข้อ ๓๖** เมื่อที่ประชุมกำลังพิจารณาญัตติใดอยู่ ห้ามเสนอญัตติอื่นมาพิจารณา เว้นแต่ญัตติ ดังต่อไปนี้

<!-- page 8 -->

- (๑) ขอให้รวมระเบียบวาระการประชุมเป็นเรื่องเดียวกัน ทำนองเดียวกัน หรือเกี่ยวเนื่องกันเพื่อพิจารณาพร้อมกัน
- (๒) ขอให้ส่งปัญหาไปยังคณะกรรมาธิการเพื่อพิจารณา หรือขอให้บุคคลใดส่งเอกสารหรือมาแถลงข้อเท็จจริงหรือแสดงความคิดเห็น
- (๓) ขอให้รวมหรือแยกประเด็นพิจารณาหรือลงมติ
- (๔) ขอให้เลื่อนการปรึกษาหรือพิจารณา
- (๕) ขอให้ปิดอภิปราย
- (๖) ขอให้ยกเรื่องอื่นขึ้นปรึกษาหรือพิจารณา

<a id="clause-37"></a>**ข้อ ๓๗** ญัตติตามข้อ ๓๖ (๕) และ (๖) ห้ามเสนอในคราวเดียวกับการอภิปรายของตน

<a id="clause-38"></a>**ข้อ ๓๘** ในกรณีที่ที่ประชุมลงมติให้ยกเรื่องอื่นขึ้นปรึกษาหรือพิจารณา ให้ญัตติเดิมเป็นอันตกไป

<a id="clause-39"></a>**ข้อ ๓๙** ญัตติที่เสนอล่วงหน้าเป็นหนังสือ ให้ผู้รับรองญัตติแสดงการรับรองโดยวิธียกมือขึ้นพ้นศีรษะ

ในการประชุมผ่านสื่ออิเล็กทรอนิกส์ ให้ผู้รับรองญัตติแสดงการรับรองตามหลักเกณฑ์และวิธีการที่ประธานกำหนด

<a id="clause-40"></a>**ข้อ ๔๐** ญัตติที่บรรจุเข้าระเบียบวาระการประชุมแล้ว หากผู้เสนอญัตติจะถอนญัตติหรือจะแก้ไขเพิ่มเติมหรือจะถอนชื่อจากการเป็นผู้ร่วมกันเสนอ หรือผู้รับรองจะถอนการรับรองญัตติจะต้องได้รับความยินยอมของที่ประชุม

<a id="clause-41"></a>**ข้อ ๔๑** ญัตติใดถึงวาระพิจารณาในที่ประชุมแล้ว การเสนอญัตติซึ่งมีหลักการเดียวกันจะกระทำมิได้

ถ้าผู้เสนอญัตติหรือผู้แปรญัตติไม่ชี้แจงในที่ประชุม หรือผู้เสนอญัตติหรือผู้แปรญัตติไม่อยู่ในที่ประชุมโดยไม่มีผู้ชี้แจงแทนในฐานะผู้มอบหมาย ญัตติหรือคำแปรญัตตินั้นเป็นอันตกไป

การมอบหมายให้ชี้แจงแทนต้องทำเป็นหนังสือยื่นต่อประธานสภา

<a id="clause-42"></a>**ข้อ ๔๒** ญัตติใดตกไปแล้ว ห้ามนำญัตติซึ่งมีหลักการเช่นเดียวกันขึ้นเสนออีกในสมัยประชุมเดียวกัน เว้นแต่ญัตติที่ยังไม่ได้มีการลงมติหรือญัตติที่ประธานสภาอนุญาตเมื่อพิจารณาเห็นว่าเหตุการณ์ได้เปลี่ยนแปลงไป

> [ภาพ: ในต้นฉบับ ข้อความตั้งแต่ “ติที่ประธานสภาอนุญาตเมื่อพิจารณาเห็นว่าเหตุการณ์ได้เปลี่ยนแปลงไป” ท้ายข้อ ๔๒ มีการไฮไลต์สีเหลือง]

<a id="clause-43"></a>**ข้อ ๔๓** ญัตติใดที่บรรจุเข้าระเบียบวาระการประชุมแล้ว หากสภาไม่ได้พิจารณาในสมัยประชุมนั้นให้เป็นอันตกไป

<!-- page 9 -->

### ส่วนที่ ๓ การอภิปราย

<a id="clause-44"></a>**ข้อ ๔๔** ผู้มีสิทธิอภิปรายก่อน คือ ผู้เสนอญัตติหรือผู้แปรญัตติ ในกรณีผู้เสนอญัตติหรือผู้แปรญัตติมีหลายคน ให้ประธานอนุญาตให้อภิปรายก่อนได้เพียงคนเดียว

กรรมาธิการซึ่งได้สงวนความเห็น กรรมาธิการผู้รับมอบหมายจากกรรมาธิการซึ่งได้สงวนความเห็น หรือสมาชิกหรือกรรมาธิการผู้รับมอบหมายจากผู้แปรญัตติซึ่งได้สงวนคำแปรญัตติในชั้นคณะกรรมาธิการ ให้มีฐานะเสมือนเป็นผู้แปรญัตติด้วย

<a id="clause-45"></a>**ข้อ ๔๕** ถ้ามีผู้อภิปรายหลายคน ประธานจะให้คนใดอภิปรายก็ได้ แต่ให้คำนึงถึงผู้เสนอญัตติ ผู้แปรญัตติ และผู้ซึ่งยังไม่ได้อภิปรายด้วย

<a id="clause-46"></a>**ข้อ ๔๖** การอภิปรายต้องอยู่ในประเด็นหรือเกี่ยวกับประเด็นที่กำลังปรึกษากันอยู่ ต้องไม่ฟุ่มเฟือยวนเวียน ซ้ำซากหรือซ้ำกับผู้อื่น และห้ามไม่ให้นำเอกสารใด ๆ มาอ่านให้ที่ประชุมฟังโดยไม่จำเป็น และห้ามไม่ให้นำวัตถุใด ๆ เข้ามาแสดงในที่ประชุม เว้นแต่ประธานอนุญาต

ห้ามผู้อภิปรายแสดงกิริยาหรือใช้วาจาอันไม่สุภาพ และห้ามกล่าวถึงสมาชิกหรือบุคคลใดโดยไม่จำเป็น

<a id="clause-47"></a>**ข้อ ๔๗** ถ้าประธานเห็นว่าผู้ใดได้อภิปรายพอสมควรแล้ว ประธานจะให้ผู้นั้นหยุดอภิปรายก็ได้

<a id="clause-48"></a>**ข้อ ๔๘** สมาชิกผู้ใดต้องการประท้วงว่ามีการฝ่าฝืนข้อบังคับหรือระเบียบ ให้ทำการยกมือขึ้นพ้นศีรษะ โดยที่ประธานต้องให้โอกาสผู้นั้นชี้แจง แล้วให้ประธานวินิจฉัยว่าได้มีการฝ่าฝืนข้อบังคับตามที่ประท้วงหรือไม่

ในการประชุมผ่านสื่ออิเล็กทรอนิกส์ ให้สมาชิกแสดงความต้องการประท้วงว่ามีการฝ่าฝืนข้อบังคับหรือระเบียบ ตามหลักเกณฑ์และวิธีการที่ประธานกำหนด

ให้นำความในวรรคหนึ่งและวรรคสองมาใช้บังคับโดยอนุโลมแก่ผู้ถูกอภิปรายพาดพิงถึงเรื่องส่วนตัวหรืออื่นใดอันเป็นที่เสียหายแก่ผู้นั้น

<a id="clause-49"></a>**ข้อ ๔๙** เมื่อมีผู้ประท้วงตามข้อ ๔๘ ผู้อภิปรายอาจถอนคำพูดของตนหรือตามคำวินิจฉัยของประธาน ถ้าผู้อภิปรายออกไปจากที่ประชุมสภาโดยไม่ถอนคำพูดตามคำวินิจฉัยของประธาน ให้ประธานบันทึกการไม่ปฏิบัติตามคำวินิจฉัยไว้ในรายงานการประชุม

<a id="clause-50"></a>**ข้อ ๕๐** การอภิปรายเป็นอันยุติ เมื่อ

- (๑) ไม่มีผู้ใดอภิปราย
<!-- page 10 -->
- (๒) ที่ประชุมลงมติให้ปิดอภิปราย
- (๓) ที่ประชุมลงมติให้ยกเรื่องอื่นขึ้นปรึกษา

<a id="clause-51"></a>**ข้อ ๕๑** ในกรณีที่ประธานพิจารณาเห็นว่าได้อภิปรายกันพอสมควรแล้ว จะขอให้ที่ประชุมวินิจฉัยว่าปิดอภิปรายหรือไม่ก็ได้

<a id="clause-52"></a>**ข้อ ๕๒** เมื่อการอภิปรายได้ยุติแล้ว ห้ามผู้ใดอภิปรายอีก เว้นแต่ที่ประชุมจะต้องลงมติในเรื่องนั้น จึงให้ผู้ซึ่งมีสิทธิอภิปรายก่อนคนใดคนหนึ่งในแต่ละญัตติ มีสิทธิอภิปรายสรุปได้อีกครั้งหนึ่งเป็นครั้งสุดท้ายก่อนที่ประชุมจะลงมติ

<a id="clause-53"></a>**ข้อ ๕๓** ถ้าประธานให้สัญญาณด้วยการเคาะค้อนหรือยืนขึ้นหรือวิธีการอื่นใดตามสมควร ให้ผู้ที่กำลังพูด หยุดพูดและนั่งลงทันที

### ส่วนที่ ๔ การลงมติ

<a id="clause-54"></a>**ข้อ ๕๔** ในกรณีที่จะต้องมีมติของสภา ให้ประธานมีสัญญาณให้สมาชิกทราบก่อนลงมติ

<a id="clause-55"></a>**ข้อ ๕๕** เสียงข้างมากนั้น หากความเห็นของที่ประชุมมีตั้งแต่สองฝ่ายขึ้นไป ให้ถือเอาจำนวนคะแนนเสียงฝ่ายที่มากที่สุด

ในกรณีคะแนนเสียงเท่ากัน ให้ประธานออกเสียงเพิ่มขึ้นอีกเสียงหนึ่งเป็นเสียงชี้ขาด

<a id="clause-56"></a>**ข้อ ๕๖** การออกเสียงลงคะแนนให้กระทำเป็นการเปิดเผย แต่เมื่อสมาชิกเสนอญัตติโดยมีผู้รับรองไม่น้อยกว่าหนึ่งในสี่ขององค์ประชุมขอให้กระทำเป็นการลับ จึงให้ลงคะแนนลับ

ในกรณีที่สมาชิกเสนอญัตติให้ลงคะแนนลับตามวรรคหนึ่ง ถ้ามีสมาชิกคัดค้านและมีผู้รับรองไม่น้อยกว่าหนึ่งในสามขององค์ประชุม ให้ถือเป็นเอกสิทธิ์ที่จะลงคะแนนโดยเปิดเผย

การออกเสียงลงคะแนนจะกระทำแทนกันมิได้

<a id="clause-57"></a>**ข้อ ๕๗** การออกเสียงลงคะแนนเปิดเผยมีวิธีปฏิบัติ ดังต่อไปนี้

- (๑) ทำการยกมือขึ้นพ้นศีรษะ
- (๒) แสดงการออกเสียงแบบระบุตัวตนผ่านสื่ออิเล็กทรอนิกส์ ตามที่ประธานกำหนด
<!-- page 11 -->
- (๓) วิธีการอื่นใดซึ่งที่ประชุมเห็นสมควรเฉพาะกรณี

การออกเสียงลงคะแนนตาม (๒) หากสื่ออิเล็กทรอนิกส์ขัดข้องให้เปลี่ยนวิธีการตามที่ประธานกำหนด

การออกเสียงลงคะแนนให้ใช้วิธีตาม (๑) จะใช้วิธีตาม (๒) หรือ (๓) ได้ต่อเมื่อสมาชิกเสนอญัตติและที่ประชุมอนุมัติ หรือมีการประชุมผ่านสื่ออิเล็กทรอนิกส์ หรือเมื่อมีการนับคะแนนเสียงใหม่ตามข้อ ๕๙

การออกเสียงลงคะแนนตามวรรคสอง กรณีประธานเห็นสมควร ให้ประธานเชิญสมาชิกไม่น้อยกว่าสามคนเป็นผู้ตรวจนับคะแนน

<a id="clause-58"></a>**ข้อ ๕๘** การออกเสียงลงคะแนนลับมีวิธีปฏิบัติ ดังต่อไปนี้

- (๑) เขียนเครื่องหมายบนแผ่นกระดาษ แล้วพับปิดอย่างมิดชิด โดยผู้เห็นชอบให้เขียนว่า “ เห็นชอบ ” ผู้ไม่เห็นชอบให้เขียนว่า “ ไม่เห็นชอบ ” ส่วนผู้ไม่ออกเสียงให้เขียนว่า “ งดออกเสียง ”
- (๒) แสดงการออกเสียงแบบไม่ระบุตัวตนผ่านสื่ออิเล็กทรอนิกส์ ตามที่ประธานกำหนด
- (๓) วิธีการอื่นใดซึ่งที่ประชุมเห็นสมควรเฉพาะกรณี

ให้นำความในข้อ ๕๗ วรรคสอง วรรคสามและวรรคสี่ มาใช้บังคับโดยอนุโลม

<a id="clause-59"></a>**ข้อ ๕๙** เมื่อมีการออกเสียงลงคะแนนตามข้อ ๕๗ (๑) แล้ว ถ้าสมาชิกร้องขอให้มีการนับใหม่ โดยมีผู้รับรองไม่น้อยกว่าสิบคน ก็ให้มีการนับคะแนนเสียงใหม่โดยกระทำตามเดิมได้อีกหนึ่งครั้ง

ถ้าสมาชิกร้องขอให้มีการนับใหม่เป็นครั้งที่สอง โดยมีผู้รับรองไม่น้อยกว่าสิบคน ให้เปลี่ยนวิธีการลงคะแนนเสียงเป็นวิธีตามข้อ ๕๗ (๒) หรือ (๓) เว้นแต่คะแนนเสียงต่างกันเกินกว่าสิบห้าคะแนนจะขอให้มีการนับคะแนนเสียงใหมไม่ได้

<a id="clause-60"></a>**ข้อ ๖๐** ญัตติใดไม่มีผู้คัดค้าน ให้ประธานถามที่ประชุมว่ามีผู้เห็นเป็นอย่างอื่นหรือไม่ เมื่อไม่มีผู้เห็นเป็นอย่างอื่น ให้ถือว่าที่ประชุมลงมติเห็นชอบด้วยญัตตินั้น

## หมวด ๓ กรรมาธิการ

<a id="clause-61"></a>**ข้อ ๖๑** คณะกรรมาธิการสามัญจะมีขึ้นได้ด้วยความเห็นชอบจากสมาชิกเกินกึ่งหนึ่งของจำนวนสมาชิกทั้งหมดเท่าที่มีอยู่ของสภา
<!-- page 12 -->
สมาชิกคนหนึ่งจะต้องสังกัดคณะกรรมาธิการสามัญอย่างน้อยหนึ่งคณะ

แต่ละคณะประกอบด้วยกรรมาธิการ มีจำนวนไม่น้อยกว่าหกคน จากไม่น้อยกว่าสองพรรค เว้นกรณีสภาประกอบด้วยสมาชิกจากเพียงพรรคเดียว โดยให้มีอำนาจหน้าที่ตามประกาศสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ เรื่อง อำนาจหน้าที่คณะกรรมาธิการ

> [ภาพ: ข้อความข้อ ๖๑ วรรคแรก (ตั้งแต่ “ข้อ ๖๑” ถึง “ของสภา” ต่อเนื่องหน้า) มีการไฮไลต์สีเหลืองในต้นฉบับ]

<a id="clause-62"></a>**ข้อ ๖๒** การตั้งคณะกรรมาธิการวิสามัญ สามารถกระทำได้ เพื่อดำเนินการเฉพาะเรื่องใดเรื่องหนึ่งซึ่งอยู่นอกเหนืออำนาจหน้าที่ของคณะกรรมาธิการสามัญ หรือตามที่สภาเห็นสมควร

คณะกรรมาธิการวิสามัญสิ้นสุดลงเมื่อการดำเนินการนั้นแล้วเสร็จ

<a id="clause-63"></a>**ข้อ ๖๓** การเลือกตั้งประธานคณะกรรมาธิการ ให้เป็นไปตามมติของที่ประชุมสภา

> [ภาพ: ข้อความข้อ ๖๓ ทั้งข้อ (ยกเว้นตัวอักษรท้าย “า” ของคำว่า “สภา”) มีการไฮไลต์สีเหลืองในต้นฉบับ]

<a id="clause-64"></a>**ข้อ ๖๔** การประชุมคณะกรรมาธิการ สามารถนำระเบียบนี้เฉพาะที่เกี่ยวกับการประชุมสภามาใช้บังคับโดยอนุโลม

ให้ประธานคณะกรรมาธิการแต่ละคณะตั้งรองประธาน เลขานุการ และตำแหน่งอื่นตามความจำเป็นจากกรรมาธิการในคณะนั้น

กรณีที่มีการแต่งตั้งกรรมาธิการให้ดำรงตำแหน่งรองประธานมากกว่าหนึ่งคน หรือตำแหน่งอื่นตามวรรคสอง ประธานคณะกรรมาธิการต้องแจ้งให้ประธานสภาและที่ประชุมคณะกรรมาธิการทราบถึงความจำเป็นดังกล่าว

<a id="clause-65"></a>**ข้อ ๖๕** เมื่อไม่มีผู้ดำรงตำแหน่งประธานคณะกรรมาธิการ หรือมีแต่ไม่สามารถปฏิบัติหน้าที่ได้ ให้รองประธานคณะกรรมาธิการเป็นผู้ปฏิบัติหน้าที่แทนประธานคณะกรรมาธิการ

ในกรณีที่มีรองประธานคณะกรรมาธิการหลายคน ให้รองประธานคณะกรรมาธิการคนที่หนึ่งเป็นผู้ปฏิบัติหน้าที่แทนประธานคณะกรรมาธิการ หากรองประธานคณะกรรมาธิการคนที่หนึ่งไม่สามารถปฏิบัติหน้าที่ได้ ให้รองประธานคณะกรรมาธิการลำดับต่อไปเป็นผู้ปฏิบัติหน้าที่แทนประธานคณะกรรมาธิการ

ในกรณีไม่มีผู้ปฏิบัติหน้าที่ตามวรรคสอง ให้กรรมาธิการคนหนึ่งเสนอชื่อกรรมาธิการคนใด เพื่อเป็นผู้ปฏิบัติหน้าที่แทนประธานคณะกรรมาธิการ เมื่อที่ประชุมคณะกรรมาธิการมีมติเห็นชอบด้วยคะแนนเสียงเกินกว่ากึ่งหนึ่งของจำนวนกรรมาธิการเท่าที่มีอยู่

<a id="clause-66"></a>**ข้อ ๖๖** เมื่อการเสนอแต่งตั้งอนุกรรมาธิการ ให้มีประกาศสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ เรื่อง การแต่งตั้งอนุกรรมาธิการ ภายในสิบห้าวัน นับตั้งแต่มีการเสนอชื่อ

อนุกรรมาธิการไม่อาจดำรงตำแหน่งตามข้อ ๖๔ วรรคสองได้
<!-- page 13 -->
อนุกรรมาธิการมีสิทธิเข้าประชุมสภา แต่ไม่มีสิทธิลงคะแนนเสียงในเรื่องต่าง ๆ ของสภา และหากประธานคณะกรรมาธิการเห็นสมควรจะไม่ให้อนุกรรมาธิการเข้าประชุมก็ได้

<a id="clause-67"></a>**ข้อ ๖๗** คณะกรรมาธิการมีอำนาจตั้งคณะอนุกรรมาธิการเพื่อพิจารณาปัญหาอันอยู่ในอำนาจหน้าที่ของคณะกรรมาธิการ แล้วรายงานคณะกรรมาธิการภายในเวลาที่คณะกรรมาธิการกำหนด

ในกรณีที่คณะอนุกรรมาธิการกระทำกิจการ พิจารณาสอบสวน หรือศึกษาเรื่องใดไม่เสร็จในเวลาที่กำหนด ให้ประธานคณะอนุกรรมาธิการขออนุญาตขยายเวลาต่อที่ประชุมคณะกรรมาธิการ

คณะอนุกรรมาธิการแต่ละคณะประกอบด้วยอนุกรรมาธิการมีจำนวนไม่เกินเจ็ดคน โดยให้ตั้งจากบุคคลที่เป็นกรรมาธิการในคณะนั้นมีจำนวนไม่น้อยกว่าสามคนของจำนวนอนุกรรมาธิการทั้งหมดและประธานคณะอนุกรรมาธิการต้องเป็นกรรมาธิการ จำนวนนอกจากนั้นให้ที่ประชุมคณะกรรมาธิการเลือกจากรายชื่อกรรมาธิการเสนอ

> [ภาพ: ข้อความ “คณะอนุกรรมาธิการแต่ละคณะประกอบด้วยอนุกรรมาธิการมีจำนวนไม่เกินเจ็ดค” (ต้นวรรคสามของข้อ ๖๗) มีการไฮไลต์สีเหลืองในต้นฉบับ]

<a id="clause-68"></a>**ข้อ ๖๘** เมื่อคณะกรรมาธิการสามัญได้กระทำกิจการ พิจารณาสอบสวน หรือศึกษาเรื่องใด ๆ ตามอำนาจหน้าที่หรือตามที่สภามอบหมาย ให้คณะกรรมาธิการสามัญรายงานให้ประธานสภาทราบ ในการกระทำกิจการ พิจารณาสอบสวน หรือศึกษาเรื่องใด ๆ ต้องไม่เป็นเรื่องซ้ำซ้อนกับคณะกรรมาธิการอื่น  ในกรณีที่การกระทำนั้นเกี่ยวข้องกัน ให้เป็นหน้าที่ของประธานสภาที่จะต้องดำเนินการให้คณะกรรมาธิการสามัญที่เกี่ยวข้องกันทุกคณะร่วมกันดำเนินการ

<a id="clause-69"></a>**ข้อ ๖๙** เมื่อคณะกรรมาธิการได้กระทำกิจการ พิจารณาสอบสวน หรือศึกษาเรื่องใด ๆ เสร็จสิ้นแล้ว ให้รายงานต่อสภา โดยแจ้งให้ประธานสภาทราบ เพื่อบรรจุเข้าระเบียบวาระการประชุมตามข้อ ๑๓ (๔)

ในที่ประชุมสภา คณะกรรมาธิการมีสิทธิแถลง ชี้แจง หรือแก้ไขเพิ่มเติมเกี่ยวกับการกระทำดังกล่าวในวรรคหนึ่ง ในการนี้ คณะกรรมาธิการอาจมอบหมายให้บุคคลใดแถลงหรือชี้แจงแทนก็ได้ เมื่อได้รับอนุญาตจากประธาน

<a id="clause-70"></a>**ข้อ ๗๐** ถ้าสภามีมติให้คณะกรรมาธิการใดกระทำกิจการ พิจารณาสอบสวน หรือศึกษาเรื่องใดให้เสร็จภายในกำหนดเวลาใด และคณะกรรมาธิการนั้นกระทำกิจการ พิจารณาสอบสวน หรือศึกษาไม่เสร็จภายในเวลาที่กำหนด ประธานคณะกรรมาธิการต้องรายงานให้ประธานสภาทราบโดยด่วน หรือขอให้สภามีมติขยายเวลา

<a id="clause-71"></a>**ข้อ ๗๑** กรรมาธิการพ้นจากตำแหน่ง เมื่อ

- (๑) สภาสิ้นอายุ
- (๒) ตาย
<!-- page 14 -->
- (๓) ลาออก
- (๔) มีการตั้งคณะกรรมาธิการใหม่แทนคณะเดิม
- (๕) ขาดการประชุมสามครั้งติดต่อกันโดยไม่มีเหตุผลอันสมควร และไม่ได้แจ้งเป็นหนังสือให้ประธานคณะกรรมาธิการทราบ
- (๖) สภามีมติให้พ้นจากตำแหน่ง ตามญัตติในข้อ ๓๑

<a id="clause-72"></a>**ข้อ ๗๒** อนุกรรมาธิการพ้นจากตำแหน่ง เมื่อ

- (๑) สภาสิ้นอายุ
- (๒) ตาย
- (๓) ลาออก
- (๔) มีการยุบคณะกรรมาธิการที่สังกัด
- (๕) คณะกรรมาธิการที่สังกัดมีมติให้พ้นจากตำแหน่ง

เมื่ออนุกรรมาธิการพ้นจากตำแหน่งโดยวิธีใด ๆ ที่ไม่ใช่ (๑) ให้มีการรายงานเป็นหนังสือต่อประธานสภาและให้มี ประกาศสภานักศึกษามหาวิทยาลัยธรรมศาสตร์ เรื่อง การสิ้นสภาพของอนุกรรมาธิการ ภายในสิบห้าวันนับตั้งแต่ได้รับรายงาน

<a id="clause-73"></a>**ข้อ ๗๓** ในกรณีที่ตำแหน่งกรรมาธิการในคณะกรรมาธิการใดว่างลง ให้เป็นอำนาจของประธานคณะกรรมาธิการในการแต่งตั้งสมาชิกเป็นกรรมาธิการแทนโดยต้องแจ้งให้ประธานสภาทราบถึงการแต่งตั้งนั้นภายในเจ็ดวันนับแต่วันแต่งตั้ง

<a id="clause-74"></a>**ข้อ ๗๔** ผู้เข้าร่วมการประชุมคณะกรรมาธิการ นอกจากกรรมาธิการและอนุกรรมาธิการ  ให้ถือเป็นผู้สังเกตการณ์

ผู้สังเกตการณ์มีสิทธิเข้าประชุมคณะกรรมาธิการ แต่ไม่มีสิทธิลงคะแนนเสียงและปฏิบัติหน้าที่ในเรื่องต่าง ๆ ของคณะกรรมาธิการ

ผู้สังเกตการณ์ไม่สามารถออกความเห็นเข้าไปในบริเวณที่ประชุมหรือสำนักงานของคณะกรรมาธิการ ให้หมายรวมถึงช่องทางผ่านสื่ออิเล็กทรอนิกส์ ทั้งนี้ เว้นแต่ได้รับคำอนุญาตจากประธานคณะกรรมาธิการให้เป็นอื่น แล้วแต่กรณี
<!-- page 15 -->
หากประธานคณะกรรมาธิการเห็นสมควร จะไม่ให้ผู้สังเกตการณ์เข้าประชุมก็ได้ โดยอาจแจ้งเหตุผลในภายหลัง และให้คำวินิจฉัยของประธานคณะกรรมาธิการถือเป็นเด็ดขาด

## หมวด ๔ การจัดระเบียบและความเรียบร้อย

<a id="clause-75"></a>**ข้อ ๗๕** ห้ามกระทำการใด ๆ อันเป็นการรบกวนต่อการประชุมสภา

<a id="clause-76"></a>**ข้อ ๗๖** ผู้ใดฝ่าฝืนระเบียบนี้ ประธานมีอำนาจเตือน ห้ามปราม ให้ถอนคำพูด ห้ามพูดในเรื่องที่กำลังปรึกษากันอยู่ ให้กล่าวขออภัยในที่ประชุม หรือสั่งให้ออกไปจากที่ประชุมโดยมีหรือไม่มีกำหนดเวลาในครั้งนั้นก็ได้

ในกรณีที่ประธานสั่งให้ผู้ใดออกจากที่ประชุม หากผู้นั้นขัดขืน ประธานมีอำนาจสั่งให้เจ้าหน้าที่รักษาความปลอดภัยนำตัวออกจากสถานที่ประชุมหรือออกไปพ้นบริเวณสภา

ในการประชุมผ่านสื่ออิเล็กทรอนิกส์ หากผู้นั้นขัดขืน ประธานมีอำนาจขับออกจากที่ประชุมตามวิธีการที่ประธานกำหนด

คำสั่งของประธานตามข้อนี้ ถือเป็นที่สิ้นสุด

## หมวด ๕ การพ้นจากตำแหน่งของกรรมการบริหารสภา

<a id="clause-77"></a>**ข้อ ๗๗** กรรมการบริหารสภาพ้นจากตำแหน่ง เมื่อ

- (๑) สภาสิ้นอายุ
- (๒) ตาย
- (๓) ลาออก
- (๔) พ้นจากตำแหน่งสมาชิก
<!-- page 16 -->
- (๕) สภามีมติให้พ้นจากตำแหน่ง ตามญัตติในข้อ ๓๐ ด้วยคะแนนเสียงเห็นชอบไม่น้อยกว่าสองในสามของจำนวนสมาชิกเท่าที่มีอยู่ของสภา

## หมวด ๖ บทสุดท้าย

<a id="clause-78"></a>**ข้อ ๗๘** ถ้าประธานขอปรึกษา หรือสมาชิกเสนอญัตติโดยมีสมาชิกรับรองไม่น้อยกว่าสิบคน ให้งดใช้ข้อบังคับข้อหนึ่งข้อใดทั้งหมดหรือบางส่วนเป็นการชั่วคราวเฉพาะกรณี หากที่ประชุมอนุมัติด้วยคะแนนเสียงไม่น้อยกว่าสองในสามของสมาชิกในที่ประชุมก็ให้งดใช้ได้

<a id="clause-79"></a>**ข้อ ๗๙** ถ้าประธานสภาวินิจฉัยแล้วว่าการดำเนินงานใดเป็นเรื่องเร่งด่วนอย่างยิ่ง ให้คณะกรรมการบริหารสภาและคณะกรรมการประสานงานร่วมสภา มีมติเห็นชอบในไม่น้อยกว่าสองในสามของจำนวนกรรมการเท่าที่มีอยู่ของแต่ละคณะ โดยต้องแจ้งสมาชิกให้ทราบถึงเหตุผลและการดำเนินการดังกล่าว จึงจะถือว่าเป็นมติสภาโดยอนุโลม

<a id="clause-80"></a>**ข้อ ๘๐** ถ้ามีปัญหาที่จะต้องตีความตามระเบียบนี้ ให้เป็นอำนาจของสภาที่จะวินิจฉัย และเมื่อที่ประชุมได้ลงมติวินิจฉัยโดยคะแนนเสียงไม่น้อยกว่ากึ่งหนึ่งของจำนวนสมาชิกเท่าที่มีอยู่ของสภาเป็นประการใดแล้ว ให้ถือว่าคำวินิจฉัยนั้นเป็นเด็ดขาด

การขอให้ที่ประชุมวินิจฉัยตามวรรคหนึ่ง อาจกระทำได้โดยประธานขอปรึกษาหรือสมาชิกเสนอญัตติ โดยมีสมาชิกรับรองไม่น้อยกว่าสิบห้าคน

<a id="clause-81"></a>**ข้อ ๘๑** การขอแก้ไขเพิ่มเติมระเบียบนี้ ต้องเสนอเป็นญัตติโดยมีสมาชิกรับรองไม่น้อยกว่าสิบห้าคน การลงมติแก้ไขเพิ่มเติมระเบียบนี้ ต้องได้รับการอนุมัติด้วยคะแนนเสียงไม่น้อยกว่าสองในสามของจำนวนสมาชิกทั้งหมดเท่าที่มีอยู่ของสภา

<a id="clause-82"></a>**ข้อ ๘๒** การคัดค้านคำวินิจฉัย หรือดุลพินิจของประธาน สามารถกระทำได้ในกรณีที่สมาชิกเสนอญัตติให้มีมติคัดค้านโดยมีสมาชิกรับรองไม่น้อยกว่าสิบห้าคน และมีคะแนนเกินกึ่งหนึ่งขององค์ประชุม เว้นแต่คำวินิจฉัยซึ่งถือเป็นที่สิ้นสุดตามระเบียบนี้
<!-- page 17 -->

## บทเฉพาะกาล

<a id="clause-83"></a>**ข้อ ๘๓** ระเบียบนี้ไม่กระทบกระเทือนถึงการใดที่ได้กระทำเสร็จไปแล้วก่อนใช้ระเบียบนี้ ส่วนการใดที่ยังกระทำค้างอยู่ให้ดำเนินการต่อไปตามระเบียบที่ใช้อยู่ก่อนวันใช้ระเบียบนี้

# ประกาศมหาวิทยาลัยธรรมศาสตร์
## เรื่อง หลักเกณฑ์การนำรถเข้า - ออก การจราจรและการจัดเก็บค่าธรรมเนียม ในบริเวณมหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์ พ.ศ. ๒๕๕๕

โดยที่เป็นการสมควรกำหนดให้มีหลักเกณฑ์การนำรถเข้า - ออก การจราจรและการจัดเก็บค่าธรรมเนียมในบริเวณมหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์ เพื่อให้การดำเนินงานด้านการจราจรเป็นไปด้วยความเรียบร้อย และมีประสิทธิภาพยิ่งขึ้นมหาวิทยาลัยขอกำหนดข้อปฏิบัติการนำรถเข้า-ออก การจราจรและการจัดเก็บค่าธรรมเนียมภายในมหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

อาศัยอำนาจตามความในข้อ ๑๕ วรรคหนึ่ง แห่งระเบียบมหาวิทยาลัยธรรมศาสตร์ว่าด้วยการเงินและทรัพย์สิน พ.ศ. ๒๕๕๔ ดังนี้

“มหาวิทยาลัย” หมายความถึง มหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์

“รถ” หมายความถึง รถยนต์ รถจักรยานยนต์

“บัตรอนุญาต” หมายความถึง บัตรที่มหาวิทยาลัยออกให้แก่ผู้ขออนุญาตเพื่อใช้แสดงสำหรับนำรถเข้า - ออก ในบริเวณมหาวิทยาลัย โดยมีลักษณะ รูปแบบ และประเภท เป็นไปตามที่มหาวิทยาลัยกำหนด ซึ่งติดแสดงไว้ให้เห็นชัดเจนบริเวณหน้ารถ

“บัตรผ่านเข้า-ออก มหาวิทยาลัยธรรมศาสตร์” หมายความถึง บัตรที่มหาวิทยาลัยกำหนดให้ต้องรับและส่งคืนต่อเจ้าหน้าที่รักษาความปลอดภัยทุกครั้งที่มีการนำรถเข้า - ออก บริเวณมหาวิทยาลัย

“ค่าธรรมเนียม” หมายถึง ค่าดำเนินการในการปลดการบังคับล้อกรณีที่ฝ่าฝืนเข้ามาจอด หรือจอดรถในที่ห้ามจอด หรือจอดรถในลักษณะกีดขวางการจราจร จอดรถค้างคืนโดยไม่ได้รับอนุญาต และอื่น ๆตามที่มหาวิทยาลัยกำหนด

<a id="clause-1"></a>**ข้อ ๑** การนำรถเข้ามาในบริเวณมหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์ จะอนุญาตให้เฉพาะผู้มีบัตรอนุญาตตามที่มหาวิทยาลัยกำหนดอนุญาตให้ไว้ และต้องรับบัตรผ่านเข้า-ออก ต่อเจ้าหน้าที่รักษาความปลอดภัย และส่งคืนบัตรผ่านเข้า-ออก ดังกล่าว ต่อเจ้าหน้าที่รักษาความปลอดภัยเมื่อต้องการออกจากบริเวณมหาวิทยาลัย

<a id="clause-2"></a>**ข้อ ๒** ผู้ที่ไม่มีบัตรอนุญาต หากประสงค์และมีความจำเป็นที่จะนำรถเข้ามาภายในบริเวณมหาวิทยาลัย จะต้องปฏิบัติตามข้อกำหนดดังนี้

<!-- page 2 -->

- ๒.๑ กรณีที่เป็นรถของวิทยากรและ/หรือผู้ทรงคุณวุฒิที่ได้รับเชิญจะต้องมีจดหมายเชิญมาบรรยายหรือจดหมายอื่นๆที่ทางหน่วยงานที่เชิญมาแสดงต่อเจ้าหน้าที่รักษาความปลอดภัยประจำประตูทางเข้า
- ๒.๒ กรณีรถของบุคคลที่เข้ามารับการอบรมระยะสั้นที่คณะ/สำนัก/สถาบัน/เป็นผู้เปิดการอบรมให้ดำเนินการยื่นเรื่องขอบัตรอนุญาตชั่วคราวผ่านหน่วยงานที่จัดการอบรมเพื่อที่หน่วยงานนั้นๆจะได้ดำเนินการขออนุญาตจากมหาวิทยาลัย
- ๒.๓ กรณีรถของผู้ปกครองที่มารับ-ส่งนักศึกษาอนุญาตให้เข้าได้เฉพาะประตูทางเข้าด้านสนามหลวงและจะต้องกลับรถออกประตูทางออกด้านหอประชุมศรีบูรพา
- ๒.๔ กรณีรถส่งของจะต้องมีใบส่งของมาแสดงต่อเจ้าหน้าที่รักษาความปลอดภัยประจำประตูทางเข้า
- ๒.๕ กรณีต้องการติดต่อบุคลากรภายในมหาวิทยาลัยให้ปฏิบัติดังนี้
  - ๒.๕.๑ แจ้งทะเบียนรถให้ศูนย์รักษาความปลอดภัยทราบล่วงหน้าหมายเลขโทรศัพท์ ๑๒๓
  - ๒.๕.๒ กรณีไม่สามารถแจ้งล่วงหน้าได้ ให้บุคลากร โทรศัพท์แจ้งเจ้าหน้าที่รักษาความปลอดภัยทราบ เจ้าหน้าที่รักษาความปลอดภัยประจำประตูทางเข้าด้านหอประชุมมหาวิทยาลัยโทรศัพท์หมายเลข ๓๐๓๖ เจ้าหน้าที่รักษาความปลอดภัยประจำประตูทางเข้าด้านท่าพระอาทิตย์โทรศัพท์หมายเลข ๓๐๓๕

<a id="clause-3"></a>**ข้อ ๓** ในกรณีที่บัตรผ่านเข้า-ออก มหาวิทยาลัยธรรมศาสตร์ สูญหายหรือเสียหาย ผู้ประสงค์จะนำรถออกจากบริเวณมหาวิทยาลัยต้องแสดงหลักฐานที่แสดงถึงการเป็นผู้มีกรรมสิทธิ์ หรือสิทธิครอบครองรถคันดังกล่าว และกรอกแบบฟอร์มขอนำรถออกจากบริเวณมหาวิทยาลัยต่อเจ้าหน้าที่รักษาความปลอดภัยที่ศูนย์รักษาความปลอดภัย อาคารอเนกประสงค์ ๑ ชั้น ๑ และต้องชำระค่าธรรมเนียมตามอัตราที่กำหนดไว้ในข้อ ๑๑ (๒)

<a id="clause-4"></a>**ข้อ ๔** ในกรณีที่ฝ่าฝืนนำรถเข้าในบริเวณมหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์ โดยไม่ได้รับอนุญาตและไม่ยินยอมรับบัตรผ่านเข้า-ออก มหาวิทยาลัยจะไม่อนุญาตให้นำรถเข้าจอดในบริเวณมหาวิทยาลัย ผู้ฝ่าฝืนจะถูกบังคับล้อและต้องกรอกแบบฟอร์มการขอนำรถออกจากบริเวณมหาวิทยาลัยต่อเจ้าหน้าที่รักษาความปลอดภัยที่ศูนย์รักษาความปลอดภัย อาคารอเนกประสงค์ ๑ ชั้น ๑ และต้องนำรถออกจากบริเวณมหาวิทยาลัยทันที โดยต้องชำระค่าธรรมเนียมตามอัตราที่กำหนดไว้ในข้อ ๑๑ (๓)

<a id="clause-5"></a>**ข้อ ๕** ผู้ที่นำรถเข้าบริเวณมหาวิทยาลัยจะต้องปฏิบัติตามเครื่องหมายจราจรที่มหาวิทยาลัยกำหนดให้มีหรือติดตั้งไว้ และตามสัญญาณจราจรของเจ้าหน้าที่รักษาความปลอดภัยของมหาวิทยาลัยโดยเคร่งครัด กรณีเป็นการขับรถเร็ว ขับย้อนศร จะทำการตักเตือนพร้อมทั้งบันทึกทะเบียนรถ ชื่อนามสกุลและหน่วยงานของผู้ขับขี่หาก ยังปฏิบัติอีกจะทำการยึดบัตรอนุญาตและห้ามนำรถเข้ามาภายในมหาวิทยาลัย

<!-- page 3 -->

<a id="clause-6"></a>**ข้อ ๖** การจอดรถในบริเวณมหาวิทยาลัย ให้จอดในพื้นที่ที่มหาวิทยาลัยกำหนดให้ไว้เท่านั้น ห้ามมิให้จอดรถในที่ห้ามจอดหรือจอดรถในลักษณะกีดขวางการจราจร หากมีการฝ่าฝืนไม่ปฏิบัติตามมหาวิทยาลัยจะดำเนินการบังคับล้อ และต้องชำระค่าธรรมเนียมตามอัตราที่กำหนดไว้ในข้อ ๑๑ (๔)

<a id="clause-7"></a>**ข้อ ๗** ห้ามมิให้จอดรถค้างคืนภายในมหาวิทยาลัยโดยไม่มีเหตุอันควรและ/หรือไม่ได้รับอนุญาตจากมหาวิทยาลัยเป็นลายลักษณ์อักษร หากมีการฝ่าฝืนไม่ปฏิบัติตามมหาวิทยาลัยจะดำเนินการบังคับล้อ และจะต้องเสียค่าธรรมเนียมตามอัตราที่กำหนดไว้ในข้อที่ ๑๑(๕)

<a id="clause-8"></a>**ข้อ ๘** การขอมีบัตรอนุญาต

1. (๑) ผู้มีสิทธิขอมีบัตรอนุญาต
    - ก. (ก) อาจารย์ /ข้าราชการ/พนักงาน/ลูกจ้าง
    - ข. (ข) อาจารย์พิเศษ
    - ค. (ค) นักศึกษาปริญญาเอก/ปริญญาโท ภาคค่ำ
    - ง. (ง) อื่น ๆ ตามที่มหาวิทยาลัยเห็นสมควร
2. (๒) ให้ผู้มีสิทธิขอมีบัตรตาม (๑) ยื่นคำขอตามแบบที่มหาวิทยาลัยกำหนด ณ หมวดรักษาความปลอดภัยและการจราจร งานบริหารอาคารสถานที่พร้อมเอกสารดังนี้
    - (ก) รายการจดทะเบียนรถ
    - (ข) สำเนาทะเบียนบ้านของผู้ทำบัตรและเจ้าของรถ(กรณีที่ผู้ขอทำบัตรไม่ใช่เจ้าของรถ โดยระบุความสัมพันธ์ เช่น บิดา/มารดา/สามี/ภรรยา
    - (ค) ผู้ลงนามในแบบฟอร์มการขอบัตรอนุญาตจะต้องมีตำแหน่งไม่ต่ำกว่าเลขานุการคณะหรือเทียบเท่า

<a id="clause-9"></a>**ข้อ ๙** บัตรอนุญาตเป็นการออกให้โดยเฉพาะบุคคล ห้ามมิให้นำไปให้บุคคลอื่นใช้ต่อโดยเด็ดขาด หากฝ่าฝืนจะดำเนินการยึดบัตรอนุญาตและห้ามนำรถยนต์เข้ามาภายในมหาวิทยาลัยพร้อมทั้งแจ้งเป็นลายลักษณ์อักษรไปยังต้นสังกัดของผู้กระทำผิดเพื่อดำเนินการลงโทษทางวินัย

<a id="clause-10"></a>**ข้อ ๑๐** ห้ามมิให้ปลอมแปลงบัตรอนุญาต หากพบการกระทำผิดจะดำเนินยึดบัตรอนุญาตและดำเนินการทางวินัยและอาญา

<a id="clause-11"></a>**ข้อ ๑๑** ค่าธรรมเนียม

1. (๑) กรณีผู้ได้รับอนุญาตทำบัตรอนุญาตสูญหายและประสงค์จะขอออกบัตรอนุญาตใหม่ จะต้องชำระค่าธรรมเนียม จำนวน ๒๐๐ บาท
2. (๒) กรณีบัตรผ่านเข้า-ออก มหาวิทยาลัยธรรมศาสตร์ สูญหาย หรือเสียหาย ต้องชำระค่าธรรมเนียมเป็นเงินจำนวน ๕๐ บาท

<!-- page 4 -->

3. (๓) กรณีฝ่าฝืนนำรถเข้าในบริเวณมหาวิทยาลัยโดยไม่ได้รับอนุญาต หรือไม่รับบัตรผ่านเข้า-ออก มหาวิทยาลัยธรรมศาสตร์ ต้องชำระค่าธรรมเนียมเป็นเงินจำนวน ๔๐๐ บาท
4. (๔) กรณีฝ่าฝืนจอดรถในพื้นที่ห้ามจอดหรือพื้นที่อื่นใดในบริเวณมหาวิทยาลัย ซึ่งมิใช่พื้นที่ที่มหาวิทยาลัยกำหนดให้ไว้ ซึ่งการฝ่าฝืนมีลักษณะที่อาจก่อให้เกิดอันตรายหรือกีดขวางการจราจรภายในบริเวณมหาวิทยาลัย ต้องชำระค่าธรรมเนียมเป็นเงินจำนวน ๔๐๐ บาท
5. (๕) กรณีจอดรถค้างคืนภายในมหาวิทยาลัยโดยไม่มีเหตุอันควรหรือไม่ได้รับอนุญาตจากทางมหาวิทยาลัยเป็นลายลักษณ์อักษร ต้องชำระค่าปรับธรรมเนียมจำนวนเงิน คืนละ ๔๐๐ บาท

การชำระค่าธรรมเนียมให้ดำเนินการชำระที่ศูนย์รักษาความปลอดภัยและการจราจร อาคารอเนกประสงค์ ๑ ชั้น ๑

<a id="clause-12"></a>**ข้อ ๑๒** กรณีการฝ่าฝืนไม่ปฏิบัติตามหลักเกณฑ์การนำรถเข้า - ออก และการจราจร ในบริเวณมหาวิทยาลัยธรรมศาสตร์ ท่าพระจันทร์ ในเบื้องต้นให้ดำเนินการตักเตือน หากยังมีการฝ่าฝืนอีกให้ดำเนินการแจ้งเป็นลายลักษณ์อักษรให้หน่วยงานต้นสังกัดทราบ และหากยังปรากฏว่ามีการกระทำที่เป็นการฝ่าฝืนอีกให้ดำเนินการยึดบัตรอนุญาตและห้ามนำรถเข้าในบริเวณมหาวิทยาลัยพร้อมทั้งตัดสิทธิ์ในการขอบัตรอนุญาตอีกต่อไป
